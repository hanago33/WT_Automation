本模块是仓库顶层的工具/脚本容器，子目录按职责切分且彼此无直接 import 依赖：
- `tools/dev_utils`：开发期调试脚本（API 测试、模型列表、鼠标坐标）。
- `tools/external_capture`：跨进程 UI 自动化桥接（pywinauto + AxeWindows/UiaPeek），被上层自动化框架调用。
- `tools/ORC`：内嵌 Tesseract OCR 二进制及语言包，供 `build_image_template_library.py` 通过 `find_tesseract_executable()` 自动发现并作为 CLI 回退。
- 根级 `build_control_map_library.py`、`build_image_template_library.py`、`generate_flow_package.py`、`merge_standard_control_library.py` 均为可独立运行的 tkinter GUI 脚本，各自产出到 `control_maps/`、`image_templates/`、`flow_packages/` 等约定目录，由上层工作流按需触发。
- `tools/__init__.py` 仅做包标记，不暴露公共 API，各脚本之间通过文件系统（JSON 索引、目录结构）而非 Python import 协作。
