本模块由三个职责正交的 Python 脚本组成，通过全局可注入的回调函数实现松耦合：
- `wt_window_helpers.py`：基于 ctypes 调用 user32.dll（EnumWindows / SendMessageTimeoutW / ShowWindow / SetForegroundWindow）枚举并筛选主窗口，结合 pywinauto UIA 后端处理“打开”对话框与“Loading DWG File...”弹窗；所有外部依赖（user32、日志、flow_control 点击/聚焦）均通过 `configure_wt_window_helpers(...)` 注入到模块级 `_USER32`、`_LOG_STEP`、`_CLICK_FLOW_CONTROL` 等全局变量，默认值为空操作 lambda。
- `wt_flow_editor_utils.py`：纯数据层，解析 Inspect.exe 输出的控件树文本，将其归一化为包含 `recommendedTargetMethod/Value/Score/Reason` 的结构化字典，供上层录制器/编辑器使用；无 GUI 依赖。
- `wt_projection_helpers.py`：封装“从图片模板 + AI 提示词驱动”的投影配置流程，按阶段顺序（config_button → general_tree_item → projection_tree_item → load_from_file_button → file_name_input → apply_button → ok_button）组合 pyautogui 精确匹配与 cv2 多尺度兜底匹配，并通过 `configure_wt_projection_helpers(...)` 注入日志、flow_control、窗口激活、文件对话框确认、模板目录等依赖；同时提供 `run_ui_tars` 子进程调用 Node.js UI-TARS Runner 执行 AI 介入步骤。
依赖方向：projection 与 window helpers 互相独立，仅共享 flow_control 回调约定；flow_editor_utils 被 build_control_map_library 反向 import，不反向依赖前两者。
