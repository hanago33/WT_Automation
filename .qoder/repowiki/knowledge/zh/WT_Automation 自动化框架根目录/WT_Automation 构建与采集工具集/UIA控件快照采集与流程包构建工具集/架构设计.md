本模块由四个相互独立的单文件脚本组成，按数据流水线方向单向依赖：
- `build_control_map_library.py`（根目录）是核心数据采集器，通过 pywinauto (uia/win32) + tkinter GUI 遍历前台窗口树，调用外部 `uia_tree_dumper.exe` 补充 RawViewWalker BFS 遍历，输出 `control_maps/*.json` 实时快照；
- `tools/merge_standard_control_library.py` 扫描 `control_maps/recordings` 与 `library/library_*.json`，按 `(windowTitle, frameworkId)` 分组并以 automation_id → name+className+controlType → name 优先级去重，输出 `standard_control_catalog.json` 及低权威度报告；
- `tools/generate_flow_package.py` 读取 `operation_blueprints/*.json` 蓝图与上述 catalog，结合内置 `SYNONYMS` 同义词表将中文步骤名映射为高权威 automation_id，产出 `flow_packages/flow_definition_<id>.json`，未匹配项以 PENDING_CAPTURE 占位；
- `build_image_template_library.py` 独立于前三个脚本，使用 OpenCV + PIL + numpy 对整张截图做 Canny/自适应阈值边缘检测自动切出候选按钮区域，再由 tkinter 交互命名并持久化为 `image_templates/<category>/` 下的 PNG 模板及 `templates_index.json`。
依赖方向严格单向：snapshot → merge → generate_flow_package；图像模板采集器与其他三者无耦合。
