# D1 · 环境准备与安装（本机 / 内网双环境）

> 本篇回答：**怎么把这套系统跑起来**，包含开发机（有网）与内网机（离线）两套路径。
> 读者：第一次部署的人、接手环境的人。

---

## 1. 两套环境一览

| | 开发机（外网） | 内网机（离线） |
|---|---|---|
| 用途 | 改代码、采集、调试、投递任务 | **验证与执行**（无人值守） |
| Python | 系统 Python 3.8 / 3.11 | **便携 Python**（如 `D:\wt_python`） |
| 代码更新 | git | 增量发布包 zip |
| 网络 | 可用（可用 AI 介入） | 通常不可用（AI 介入不可用） |
| 启动 | `启动WT自动化总控台.bat` | `启动WT自动化总控台_内网.bat` |

---

## 2. 系统与版本要求

| 项 | 要求 |
|---|---|
| 操作系统 | **Windows**（依赖 UIA / Win32 / 原生输入注入） |
| Python | **3.8 与 3.11 均可运行**；文档推荐 **3.11** |
| 权限 | 目标程序（MUP）以管理员运行时，自动化进程也需**提权**（UIPI，见 B1 §7） |
| 会话 | 执行进程与 MUP 必须**同一 Windows 会话**（C5 §7） |
| 显示 | 需可交互桌面；**锁屏 / RDP 断连会导致 UI 树失效** |

> 📌 便携环境现状：3.8.10 为长期验证版本；**3.11.9 升级包已制作**（2026-09-10），切换方式与回滚见 `docs/09-规范与手册/内网便携Python环境维护手册.md`。

## 3. 依赖清单（`requirements.txt`）

| 分类 | 依赖 | 缺失时 |
|---|---|---|
| 桌面自动化核心 | `pywinauto>=0.6.8`、`pyautogui>=0.9.54`、`pynput>=1.7.6` | `pynput` 缺失 → 自动降级到 `win32_input_hook.py`（纯 ctypes 钩子，零依赖） |
| 控件库 / 图像模板构建 | `opencv-python>=4.7.0`、`numpy>=1.23.0`、`Pillow>=9.4.0` | 模板相关功能不可用；`images_are_similar` 会保守返回 `False` |
| Agent / 网络请求 | `requests>=2.28.0` | Agent 无法调用 LLM |
| Excel 读写 | `openpyxl>=3.1.0` | Excel 导入导出不可用 |
| 可选：OCR | `pytesseract>=0.3.10`（**默认注释未启用**） | 需要 OCR 能力时再装；运行时在 `tools/ORC/`（已入库） |
| 可选：界面美化 | `ttkbootstrap>=1.10.1` | 缺失 → 自动降级为**标准库现代风格** |
| 不在 PyPI | `pywinauto_recorder.player` | 需从本地 Pywinauto Recorder 安装目录获取（见 `_launch_pywinauto_recorder.cmd`）；**未安装不影响 GUI / 半自动采集 / 控件库构建** |

> 💡 **设计原则：缺失即降级**（A2 §4 原则 7）。零额外依赖也能把主流程跑起来。

## 4. 开发机安装

```powershell
# 1. 确认 Python
python --version

# 2. 安装依赖（在仓库根目录）
pip install -r requirements.txt

# 3. 启动总控台验证
启动WT自动化总控台.bat
```

**安装后自检清单**

| # | 检查 | 方法 |
|---|---|---|
| 1 | GUI 能起来 | 双击 `启动WT自动化总控台.bat` |
| 2 | 依赖齐全 | `python -c "import pywinauto, pyautogui, cv2, openpyxl"` |
| 3 | 能看见 MUP 窗口 | `python diagnose_mup_windows.py` |
| 4 | 会话正确 | `python diagnose_session.py` |
| 5 | 测试全绿 | `python -m pytest tests/ -q`（合并门槛） |

## 5. 内网机部署（离线）

### 5.1 首次部署（只做一次）

需要传 **3 个文件**：

| 文件 | 大小 | 说明 |
|---|---:|---|
| `wt_python_portable.zip` | ~212 MB | 便携 Python（解释器 + 全部依赖） |
| `release_out/全量包_*.zip` | ~120 MB | 完整项目源码 + 资产（开发机 `python make_release.py --full` 生成） |
| `deploy_release.exe` | ~4.9 MB | 日常增量更新用 |

**内网机步骤**

1. 解压 `wt_python_portable.zip` → `D:\wt_python`（解压后约 600 MB，确认磁盘空间）；
2. 解压 `全量包_*.zip` → `D:\WT_Automation`（包内即项目根结构，解压即用）；
3. 双击 **`启动WT自动化总控台_内网.bat`** 启动；
4. 打不开 → 先双击 **`验证环境_内网.bat`** 逐项排查；
5. 之后日常更新走增量流程（§5.2）。

> ⚠️ **内网机不要安装 Python，也不要直接双击 `.py`**——`.py` 依赖系统关联的 Python。启动一律用 `.bat`（内部写死便携 Python 路径；若解压到别的路径，改 bat 顶部的 `PYTHON` 变量）。

### 5.2 日常增量更新

```mermaid
graph LR
    A["开发机：改代码"] --> B["make_release.exe<br/>（必须在仓库目录内，靠 git 定位）"]
    B --> C["release_out/发布包_时间戳_短哈希.zip<br/>（通常几十 KB）"]
    C -->|传输软件| D["内网机：zip 与 deploy_release.exe 放同目录"]
    D --> E["双击 deploy_release.exe<br/>输入仓库根目录 → 回车"]
```

- 增量内容：已提交改动 + 未提交修改 + 新增未跟踪文件；自动排除临时文件、`dist/` 等；
- 命令行用法：`deploy_release.exe 发布包_xxx.zip D:\WT_Automation`；
- **删除文件**：写入 `deleted.txt`，内网机自动删除；
- 同步基准：用 git 标签 `wt_last_sync` 记录上次同步点；强制全量 → `git tag -d wt_last_sync` 后重跑；
- 中文乱码：发布包用 Python `zipfile`（UTF-8）解压，**请用 `deploy_release.exe` 而非资源管理器手动解压**。

### 5.3 外部运行时依赖（按需）

| 组件 | 位置 | 必需性 | 说明 |
|---|---|---|---|
| Tesseract OCR | 仓库内 `tools/ORC/` | 模板制作 / OCR 命名 | **随仓库增量同步，无需安装**，代码自动找到 |
| pywinauto Recorder | 开发机 Pywinauto Recorder 安装目录 | 可选（录制） | `player` 模块已在便携 Python 内；录制 GUI 需整目录拷贝 |
| UI-TARS Desktop | 开发机（Node.js 项目） | 可选（AI 介入） | 需 Node.js + 依赖；**内网通常不可用** |
| Inspect / Accessibility Insights | 系统工具 | 可选（半自动采集辅助） | 需单独安装 |

> 📌 何时需要**重做便携环境**：内网换新机器，或 `requirements.txt` 新增依赖。平时代码更新走增量包即可。

## 7. 常见问题

| 症状 | 排查 |
|---|---|
| 刚部署/切换后启动无反应（只闪一下） | **先重启电脑**（解压大环境与目录改名会留陈旧文件句柄；也可能撞上杀软首轮扫描）。仍不行 → `调试启动_显示错误.bat` 看完整报错，查 `logs/launcher_headless.log` |
| 内网提示找不到 Python | 不要在内网装 Python。跑 `验证环境_内网.bat`：第 1 步报 `Not found: D:\wt_python\python.exe` → 便携包没解压到位；第 2 步 `DEPS OK` 没出现 → 便携包损坏，重新解压；第 3 步 `WT_Launcher.py found` 没出现 → 全量包解压不完整 |
| `make_release.exe` 报找不到仓库 | exe 必须在仓库目录内运行（靠 `git rev-parse` 定位） |
| 内网缺 VC++ 运行库报错 | 把开发机 `System32\vcruntime140.dll`、`msvcp140.dll` 拷到 `D:\wt_python\` |
| 界面发虚 / 一部分窗口很小 | DPI 虚拟化，见 B1 §5；可在总控台调整"界面缩放"档位 |
