### WT软件
- 定义：Meteodyn WT 风电场仿真软件的简称，是本项目自动化的目标应用程序。项目围绕该软件的 UI 操作进行自动化封装，包括气象对象创建、风机类型配置、微尺度模拟等核心功能。
- 别名：Meteodyn WT、WT仿真软件

### flow_definition.json
- 定义：项目核心的流程定义文件格式，采用 JSON 结构描述自动化步骤序列。每个步骤包含 action 类型、controlId 控件标识、actionConfig 动作配置、stepParams 步骤参数等字段，是连接编辑器、转换器、执行器的统一数据契约。
- 别名：流程定义文件、flow文件

### control_maps
- 定义：控件映射库目录，存储 UI 控件的定义信息，包括控件 ID、自动化属性（automationId、className）、框架类型（WPF/MFC/Win32）、祖先链信息等。用于将录制的 UIPath 与实际控件建立映射关系。
- 别名：控件库、控件映射

### image_templates
- 定义：图像模板库目录，存储 UI 元素的截图模板，用于模板匹配定位。支持按功能模块分目录组织（如 Icons、Layer_tree、WT_software_Images），配合 templateKey 实现视觉兜底定位。
- 别名：模板库、截图模板

### recorder_captures
- 定义：录制截图专用子目录，存放伴随拾取功能自动截取的 UI 元素图片。命名规则为 step_{步骤N}_{控件名}.png，便于与录制步骤建立关联，用于模板匹配兜底。
- 别名：录制截图、伴随拾取截图

### a11y metadata
- 定义：无障碍元数据，指从 UI 控件的 Accessibility Tree 中提取的结构化信息，包括 automationId、className、frameworkId、ancestors 等属性。用于增强控件定位的准确性和鲁棒性。
- 别名：无障碍信息、控件元数据

### UIPath
- 定义：UI 元素路径，pywinauto_recorder 生成的控件定位字符串，采用树形路径表示控件在 UI 层次结构中的位置。支持通配符（*-）和坐标偏移（%(x,y)）语法，用于精确描述控件位置。
- 别名：控件路径、UI路径

### flow_packages
- 定义：流程包目录，存储可复用的流程模板和注册表。支持将常用操作流程打包为独立单元，便于在不同项目中共享和版本管理。
- 别名：流程包、流程模板

### WT_Launcher
- 定义：WT 自动化总控台主程序，提供图形化启动界面，统一管理各个子系统的启动和配置，包括 AI 助手、流程编辑器、录制器等组件的协调工作。
- 别名：总控台、启动器

### WT_Flow_Editor
- 定义：可视化流程编辑器主程序，基于 Tkinter 构建的 GUI 工具，支持拖拽式流程编辑、步骤参数配置、实时预览等功能，是主要的流程开发界面。
- 别名：流程编辑器、Flow Editor

### menu_select
- 定义：菜单选择动作类型，用于模拟用户点击应用程序菜单栏的操作。支持层级菜单路径（如"File->Open"），通过解析菜单段序列实现精确的菜单导航。
- 别名：菜单点击、menu_click

### select_dropdown_item_runtime
- 定义：运行时下拉框选择动作，用于动态选择下拉列表中的选项。相比静态配置，支持在执行时根据当前可用选项进行智能选择，提高流程的适应性。
- 别名：下拉框选择、combobox选择

### fallback链
- 定义：降级定位链，当主定位策略失败时依次尝试的备用方案序列。通常包括：automationId精确匹配 → name+type模糊匹配 → uiPath路径定位 → 模板匹配 → 坐标点击等多级策略。
- 别名：降级策略、回退链

### 置信度评分
- 定义：控件匹配质量评估指标，采用三级评分体系：高置信度（≥0.95）表示 automationId 精确匹配，中置信度（≥0.70）表示 name+type+祖先链匹配，低置信度（≥0.60）表示 type+proximity 匹配。
- 别名：匹配评分、confidence score

### 伴随拾取
- 定义：录制过程中的实时截图功能，在用户操作时自动截取相关 UI 元素图像，用于后续模板匹配和视觉验证。支持最小尺寸过滤和安全销毁机制，避免遮挡问题。
- 别名：实时截图、capture
