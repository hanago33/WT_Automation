## 3. 重构建议（按性价比排序）

> 均**不改功能行为**，只搬结构。

| # | 项目 | 收益 | 风险 |
|---|---|---|---|
| 1 | **把 pytest 接进 GitHub Actions** | 合并门槛从"人工自律"变成"自动拦截" | 极低 |
| 2 | **修 P1**：让 `load_all` 改 `os.walk` 递归（或采集器落 `recordings/`） | 消除"采了不进库"的认知落差 | 低 |
| 3 | 抽 `_launch_script(script_path)` 统一 4–5 处 `subprocess.Popen` | 顺带解决孤儿进程不回收 | 低 |
| 4 | 重复 helper 上提（`_strip_wrapping_quotes`、`slugify`） | 消除三份拷贝 | 低 |
| 5 | 统一 `_run_async(task, on_done)`（后台线程只经 `root.after(0, …)`） | 杜绝 Tk 线程安全问题 | 中 |
| 6 | 抽 `FlowDocumentService`（保存/校验/撤销脱离 Tk） | 可独立测试 | 中 |
| 7 | **ui_path 父链引导重定位** | 抵御父链中间节点变化 | 中（需改评分与候选） |
| 8 | `FlowEditorApp` 拆 Model / View | 长期可维护性 | 高（等现有功能稳定后） |
| 9 | 路径脱敏（35 个文件） | 合规与换机体验 | 低（但需回归） |
| 10 | 运行报告趋势化（汇总 `fallbackCount`） | 发现"定位在缓慢退化" | 低 |

## 4. 结构性风险提示

| 风险 | 说明 | 缓解 |
|---|---|---|
| **根级核心库互相 import** | 50 余个 `wt_*.py` 不能搬动 | 依赖注入 + 延迟 import（A2 §3） |
| **资产与代码耦合** | 控件库/模板/流程路径被多处引用 | 移动资产目录需同步代码、测试、文档 |
| **未跟踪文件是刚需** | `control_live_detector.py` 缺失会导致测试收集错误 | 写入 `AGENTS.md` 检查单（D1 §6） |
| **批次回归测试组** | `test_p0/p1/p2_fixes`、`test_round2_hardening` 等按"修复批次"命名，保护的是历史决策 | 改相关行为时同步更新断言，**不要放宽断言** |
| **公开仓库** | 历史中的本机路径无法靠删除工作区文件清除 | 重新评估时机见 E4 §6.3 |
