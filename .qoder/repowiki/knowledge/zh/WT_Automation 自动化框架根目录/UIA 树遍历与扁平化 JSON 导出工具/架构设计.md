单文件控制台程序（Program.cs），无分层结构：入口负责解析命令行参数（--hwnd/--pid/--title/--maxdepth/--timeout），通过 System.Windows.Automation 定位根 AutomationElement，随后使用 TreeWalker.RawViewWalker 递归遍历子节点并构建 FlatControl 记录列表，最终用 System.Text.Json 序列化为紧凑 JSON 输出。
- 数据模型 FlatControl 与 Rect 为 C# record，字段通过 [JsonPropertyName] 映射为小驼峰 JSON 键。
- 属性采集采用 try/catch 包裹的惰性访问模式，对不可访问控件返回 error="inaccessible" 标记，保证遍历鲁棒性。
- 依赖方向单一：仅依赖 System.Windows.Automation、System.Text.Json、System.Diagnostics，不对外暴露任何接口或库。
