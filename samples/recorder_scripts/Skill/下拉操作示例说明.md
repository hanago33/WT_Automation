# 下拉选择操作示例（给AI参考）

这是在Global Mapper中选择投影的下拉操作演示，告诉AI怎么正确操作下拉框：

## 操作步骤

1. 点击下拉框的"打开"按钮，展开下拉列表
2. 向下滚动鼠标滚轮（或拖动滚动条），直到找到目标选项
3. 点击目标选项
4. 重复以上步骤操作其他下拉框

## 录制的具体操作

- **投影下拉框**：点击打开 → 向下滚动 → 点击 "Gauss Krueger (3 degree zones)"
- **带号下拉框**：点击打开 → 向下滚动 → 点击 "Zone 40 (118.5E - 121.5E)"
- **基准下拉框**：点击打开 → 向下滚动 → 点击 "WGS84"

## 滚动操作说明

- 如果看不到目标选项，就向下滚动鼠标滚轮（每次滚动1-2格）
- 滚动后继续查找，找到后点击
- 如果滚动太多，可以向上滚动回去
