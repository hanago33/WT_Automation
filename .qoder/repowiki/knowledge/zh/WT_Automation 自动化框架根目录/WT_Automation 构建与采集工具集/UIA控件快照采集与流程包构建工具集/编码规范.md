- 所有 JSON 输入/输出统一使用 `encoding='utf-8'` 并通过 `ensure_ascii=False, indent=2` 序列化，保证可读性与跨平台一致性。
- 路径解析一律以 `os.path.dirname(os.path.abspath(__file__))` 推导 BASE_DIR，再以相对仓库根拼接常量（如 CONTROL_MAP_DIR、DEFAULT_OUTPUT_DIR），避免硬编码绝对路径。
- 对外部 API 调用（pywinauto element_info 属性、ctypes 返回值等）统一包裹 `_safe_get_value(getter, default)` 异常捕获，防止 UIA 访问失败导致崩溃。
- 控件标识去重采用分层 key 策略：优先 automationId，其次 name+className+controlType，再次仅 name+controlType，并以 authority 等级(high/medium/low/unknown)标记可信度。
- GUI 应用类（TemplateBuilderApp、控件库扫描主循环）在关键状态变更时调用 `push_undo_state()` 保存快照，支持 Ctrl+Z 撤回，撤销栈长度上限固定为 50。
