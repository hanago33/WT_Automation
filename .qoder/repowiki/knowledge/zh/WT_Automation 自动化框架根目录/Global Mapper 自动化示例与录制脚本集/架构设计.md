本模块为纯数据与脚本样本目录，不含可执行代码，按用途分为三层：
- `flows/`：以 JSON（flow_definition_*.json）描述业务级自动化流程，顶层包含 version/project/description/runtimeConfig 等元信息；通过 flowPackages 将一组原子步骤打包复用，steps 数组中每个 step 用 actionType（script/action/flow_ref）、strategy（script/image/ai 的降级链）、controls（UI 控件定位：automation_id/control_type/name+control_type/regex/template）和 fallbacks 字段声明具体动作与回退策略，形成“业务步骤 → 原子步骤包 → 控件动作”的三级编排结构。
- `recorder_scripts/Skill/`：由 pywinauto_recorder 生成的 .py 脚本，使用 `from pywinauto_recorder.player import *` 并通过 `with UIPath(...)` 上下文嵌套 click/send_keys/right_click 等 API 回放鼠标键盘操作，作为录制产物供人工审阅或二次编辑。
- `legacy_tests/`：基于 pyautogui 的旧版点击/投影加载回归用例，仅保留历史参考。
依赖方向单向：JSON 流程定义是上层编排，Python 录制脚本是底层输入源，二者共同服务于项目根目录下的运行时引擎（不在本模块内）。
