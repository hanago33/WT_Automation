- 所有可能抛出异常的 UIA 属性访问都包裹在 try/catch 中，失败时回退为默认值或错误标记，确保遍历不因单个控件异常而中断。
- 字符串字段统一通过 NullIfEmpty 辅助方法处理空/空白值为 null，避免 JSON 中出现空字符串。
- FlatControl 使用 C# record + [JsonPropertyName] 特性声明扁平 JSON 结构，字段命名采用小驼峰且按逻辑分组（标识、状态、几何、交互模式）。
- 命令行参数通过 switch 表达式逐项匹配 args[i].ToLowerInvariant() 并带边界检查 i+1 < args.Length，保持简洁无第三方依赖。
