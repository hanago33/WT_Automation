## 3. 实施原则（全部阶段通用）

1. **双轨不迁移**：新模型先并行读（Adapter），旧路径（控件卡直读）保持默认，回归稳定后再切默认。
2. **主实现唯一**：所有新代码只引用 `wt_flow_locator` / `wt_projection_helpers` 主实现。
3. **每项独立提交**：一个措施一个 commit + 一个单测文件，可单独回滚。
4. **不动加密/授权面**：全部为自有代码改进，与影刃仅设计模式借鉴，无任何代码拷贝。

## 4. 风险与回滚

| 风险 | 缓解 |
|---|---|
| Selector 归一引入定位行为差异 | Phase 1 双轨对照跑既有回归集；差异清单进 `standard_catalog_mismatch_report.json` 同款报告 |
| hash 不一致导致遥测错配 | `selector_hash` 算法单测锁定（写侧/读侧同源，对齐影刃"两侧算法一致性"注释） |
| flow_repair 门控误伤 | 门控仅收紧入口不改动修复逻辑；提供开关回退（env/config） |
| 事件化触发器兼容性 | v1 轮询保留为 fallback，v2 灰度 |
