## 2. 逐条判定

> 卡片说明：**判定**（先做 / 可做 / 暂缓 / 不做）；"校正"指与原文描述不符、以本卷为准。

### 2.1 P0 批次（6 项）

#### P0-1 输入通道参数化 —— 可做（第二批）
- 现状：无 `inputChannel`；但注入链比文档描述**集中得多**——`set_edit_text` 全库仅 1 个调用点，主链是三路降级（UIA 直写 → `type_keys` → 屏幕键盘），集中在 `wt_flow_locator.py` 的 3 个函数。
- 校正：原文"40+ 注入调用点"口径偏大；落点文件不是 executor 而是 `wt_flow_locator.py`。
- 注意：`tools/generic_flow/` 下有镜像副本，改动需同步评估。

#### P0-2 剪贴板 + IME 防线 —— 可做（第二批，降级立项）
- 现状：剪贴板通道确实为零；`win32clipboard` 可用（pywin32 随 pywinauto 依赖链已在）。
- 校正："中文输入法吃键在日志中反复出现"**查无实据**；项目真实输入痛点是"值写入未提交（`postInputKeys`）"与 `PART_ContentHost` 兜底。
- 结论：clipboard 通道按"预防性增强"立项；`force_ime_ENG` / 拟人延迟不做。

#### P0-3 重试 + 超时三态 —— 拆两步做
- 现状属实：`onError=retry` 且未填次数时强制 1 次、固定 1.0s 间隔；`timeoutSeconds` 67 处（集中三文件）；`sleep_seconds` 用 `max(0.0,·)` **吞掉负值**，`-1` 三态无处安放。
- 拆法：**先做**退避（`retryBackoff` 默认关）+ 默认值收敛到 `wt_action_defaults`；**`-1` 无限等后置**（须与队列 `timeout_seconds` 联动防僵尸任务）。

#### P0-4 图像参数入库 —— 可做（第二批，并入图像域批次）
- 现状：`scales` 七档与 `confidence=0.8` 硬编码属实；索引 3 份共 27 条。
- 校正：索引字段不止 3 个——实际含 `region / updatedAt / source_screenshot` 等 7 个，其中 `region` 可直接复用为 ROI。
- 前置：先统一 `image_template_index.py`（统一索引）与 `wt_projection_helpers` 旧索引两套机制。
- **升级建议**：与 Airtest 阶段 A/B/C、OpenAdapt T1 合并为"图像域批次"（见 §5）。

#### P0-5 防休眠 + 卡死登记 —— 先做（第一批 B）
- 现状属实：`SetThreadExecutionState` 零命中；已有窗口级探针 `_window_is_responsive`。
- 落点：`run_automation`（`WT_AUT_recorded.py`）单一入口，monitor / 无 monitor 两路都经过它。
- 附带：队列侧已有 `check_desktop_interactive()`（锁屏 / Session 0 检测），运行进程内复用即可，非零基础。

#### P0-6 指令目录 + Agent 技能 —— 先做（第一批 A，价值最高）
- 现状**比原文更严重**，四个实证：
  1. Agent 侧 `schemas.py` 是独立副本，与根版**已漂移**（缺 `check_all_toggles` / `select_list_items`；`click_relative_anchor` 描述与默认值落后）；
  2. `skills/*.md` 因 `load_all_skills_text()` 调用点均不传 `additional_dirs` 而**不进 prompt**（只走 RAG 按需召回）；
  3. `DslContext.action_schema_text` 是预留但空置的钩子；`agent.py` 里还有第 3 份硬编码动作枚举；
  4. 该链路 0 测试覆盖。
- 结论：这是"AI 生成流程质量"的根因修复，列入第一批。

## 4. 第一批落地要点

> 代码骨架与测试骨架见 `09` 卷；此处只给审核用的要点。

### A. P0-6' 指令目录生成器 + Agent 同源收敛

- **目标**：schema 成为"面板/校验/文档/AI 语料"四合一唯一事实源；消除 Agent 副本漂移。
- **改动**：① 新增生成器 `tools/generate_command_catalog.py` + 产物 `command_catalog.json` + 一致性测试（含"Agent 漂移白名单"护栏）+ 修正 Agent 副本已漂移项；② Agent 消费：填充 `DslContext.action_schema_text` 空置钩子、收敛硬编码枚举。
- **注意**：`ACTION_SCHEMAS` 是 **dict**（卷四示意代码 `for s in ACTION_SCHEMAS` 会迭代键名）；`STEP_POLICY`/`CONTINUE_WHEN_KINDS` 等符号名不存在，真实名见 09 卷。
- **独立决策点**：是否把 `check_all_toggles`/`select_list_items` 放开给 Agent 生成（建议先锁定现状，另立 commit）。

### B. P0-5' 防休眠 + 卡死登记

- **目标**：长跑任务不被系统休眠打断；卡死可归因。
- **改动**：① 新增 `wt_run_guards.py`（`PreventSleep` + 会话告警）+ `run_automation` 两路入口接线；② `StuckRegistry`（60s 看门狗 → JSONL `stuck_suspect` + **主线程栈**）。
- **关键实现点**：主线程栈必须用 `sys._current_frames()` 获取（巡检线程里 `traceback.format_stack()` 只会拿到自己）。

### C. P1-6 步骤参数快照

- **目标**：报告可回答"这一步当时传了什么参数"。
- **改动**：`wt_run_reporting.py` 新增快照函数（敏感键掩码 / 长值截断保头部 / `isFullValue` 标记）；executor 在 `action_config` 归一化后一处接线（`step_extra["inputsSnapshot"]`）。
- **验收**：失败步骤的 run_report 内嵌实测入参；敏感字段不泄漏；全量测试绿。
