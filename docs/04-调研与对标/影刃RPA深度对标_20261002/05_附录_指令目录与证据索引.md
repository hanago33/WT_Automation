## D. 术语表

| 术语 | 含义 |
|---|---|
| 指令（Activity/Block/Command） | 流程编排的最小单元，影刃称"指令"，可视化面板一条即一个 block |
| 选择器（Selector） | 元素的定位描述（属性链）；影刃 XML 库管理，WT 用控件库 JSON |
| 九宫格锚点（sudoku_part） | 元素矩形 3×3 区域命名（topLeft…bottomRight）+ 随机 + 像素偏移 |
| 三通道输入 | simulate（模拟人工键鼠）/ clipboard（剪贴板粘贴）/ automatic（UIA 自动化接口直写） |
| timeout 三态 | 0=不等待；>0=等 N 秒；-1=无限等（影刃全库统一） |
| Provider 进程 | 影刃的独立定位服务进程（UIA/CV/OCR），经管道服务 Python 引擎 |
| 桩代码 | 函数体为 pass、保留完整签名与 docstring 的 API 声明文件 |
| 执行审计快照 | 每条指令的输入参数值/输出值/成败/行号结构化记录 |
| xbot / xbot_visual | 影刃 Python 指令的两个包：核心层与可视化指令层 |
| self-heal | 定位成功后将新定位信息回写库，下次直接生效（WT 已有） |
