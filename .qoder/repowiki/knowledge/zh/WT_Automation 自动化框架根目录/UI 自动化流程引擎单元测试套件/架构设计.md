测试目录按被测模块一一对应组织，每个 `test_*.py` 文件聚焦一个子模块：
- `test_self_healing_locator.py` / `test_ui_path_selector.py` / `test_flow_recorder_converter.py` / `test_image_matcher_multiscale.py` 使用 pytest + `monkeypatch` 注入 FakeWrapper 模拟 pywinauto 控件树，验证自愈降级与 ui_path 唯一选择器生成逻辑。
- `test_wt_flow_executor.py` / `test_wt_run_reporting.py` / `test_wt_action_validation.py` / `test_wt_flow_editor_utils.py` / `test_wt_flow_locator_relative_window.py` 采用 unittest.TestCase，通过 `configure_flow_executor` / `configure_run_reporting` 等配置函数注入回调（`get_step_definition`、`report_step_result`、`run_ai_intervention_after_failure` 等），以纯内存断言替代真实 UI 交互。
- `test_flow_excel_io.py` 使用 `tempfile.TemporaryDirectory` 构造临时 JSON/XLSX 路径，验证 roundtrip 数据一致性；依赖可选 openpyxl 并通过 `@unittest.skipIf` 跳过缺失环境。
- `test_click_relative_anchor.py` 当前为空占位文件。
所有测试均通过 `sys.path.insert(0, PROJECT_DIR)` 将仓库根加入 import 路径，直接 `import wt_*` 加载源码，不依赖包安装。
