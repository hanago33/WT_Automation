模块采用分层设计，核心入口为 `agent.py` 中的 `DslAgent` 类，对外暴露 `nl_to_step` / `nl_to_sequence` / `chat` 三个 API。
- 配置层：`DslAgentConfig` 数据类管理 LLM 连接（base_url/api_key/model/重试），支持环境变量与 `model_profiles.json` 回退。
- Schema 层：`schemas.py` 内置完整的 ACTION_SCHEMAS 与默认配置，与主项目 `wt_action_schema.py` 保持语义一致但完全独立。
- 上下文层：`control_index.py` 从 flow_definition JSON 构建 LLM 可读的控件索引；`skill_bridge.py` 发现并加载 .md/.json/.xlsx/.csv/.pdf/.docx 格式的 Skill 知识，合并为系统提示词。
- LLM 调用层：`_call_llm` 基于 requests + urllib3 Retry 实现指数退避重试，通过 `_build_tools_definition` 动态生成 add_step/add_sequence/find_control/control_tree/add_parameter_scan 等 Function Calling 工具定义。
- 工具执行层：`_exec_find_control` 调用 `control_search.best_control_for_step` 进行控件模糊匹配；`parameter_scan.py` 提供 Excel 参数扫描能力。
- 会话持久化：`history_store.py` 以 JSON 文件存储多轮对话历史，支持会话创建/重命名/清空/删除。
- CLI/GUI 层：`cli.py` 提供命令行接口（--sequence/--list-schemas/--gui），`gui.py` 启动 Web 对话界面。
依赖方向单向：agent → schemas/control_index/skill_bridge/parameter_scan/history_store/memory/log_diagnosis，不反向依赖主项目任何模块，保证可独立运行。
