本模块由三个职责独立的脚本组成，均作为上层 Agent 能力的“外部接口层”：
- `cli.py`：基于 argparse 的命令行入口，解析 `--sequence/--chat/--gui/--list-schemas/--list-skills` 等参数后，按需延迟导入 `DslAgent`、`skill_bridge`、`gui` 等子包，完成自然语言→步骤/序列转换或启动 GUI 服务。
- `control_index.py`：纯函数式工具，将 flow_definition JSON（支持 `{steps:[{controls, inspectHints}]}` 与扁平列表两种格式）或内存字典转换为 LLM 可读的文本索引，并提供 `build_context_for_agent` 快捷构造 `DslContext`；内置 `BUILTIN_CONTROL_TEMPLATES` 覆盖 Button/Edit/ComboBox/CheckBox/RadioButton/TabItem/ListBoxItem 等常见 UI 模式。
- `parameter_scan.py`：以 `ParameterScanner` 类为核心的数据流水线，通过 `read_excel/read_csv/read_auto` 读取 .xlsx/.xls/.csv/.tsv，按行复制模板步骤并注入 `stepParams`，输出标准 `flow_definition`；同时提供 `analyze_step_excel` / `export_param_template` / `auto_scan_from_steps` 与 `flow_excel_io` 联动，实现“步骤 Excel → 参数模板 Excel → 参数化流程”的一站式桥接。
依赖方向：本模块仅向上层 `agent`、`schemas`、`skill_bridge`、`gui` 做单向调用，自身不引入任何运行时执行逻辑，保持无副作用的工具属性。
