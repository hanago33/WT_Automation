## 5. 采信原则（重要）

`.qoder/repowiki` 知识库由工具自动生成，核对源码后发现**三处硬伤与一片覆盖空白**，本目录已按源码纠正：

| 项 | `.qoder` 口径 | 实际（已核实） |
|---|---|---|
| 动作数量 | 未给出 | **19 种**（`wt_action_schema.py` L45–213） |
| 执行器 ↔ 定位器 | "强依赖、高层调低层" | **依赖注入**：模块级 `lambda` 占位 + `configure_flow_executor()`（L144）+ 函数内延迟 `import` |
| 定位机制 | "条件查询返回候选" | **全量 `descendants()` 遍历 + 加权评分取最高** |
| 覆盖空白 | 无 | 未涉及远程任务队列、参数扫描、`wt_dsl_agent`、主题/DPI/滚轮、MUP 工具族、发布三件套、`tools/generic_flow`、`tools/research`、`uia_tree_dumper` |

## 6. 维护约定

1. **事实可追溯**：每个行号、字段、权重、端口必须来自源码；文档末尾标注 `核验：<日期> / <涉及文件>`。
2. **图表**：统一 Mermaid，沿用仓库既有风格。
3. **禁止**：写入 API Key / 令牌、本机绝对路径（如 `D:\...`、`C:\Users\<某人>`）。
4. **新增文档**：先在本 README 的对应卷册表登记，再补正文。
5. **源码变更后**：凡涉及被文档引用的模块，同步更新对应章节与"核验"标记。
6. **路径与密钥纪律**：文档中路径一律用 `<仓库根>/…` 占位，不得出现本机绝对路径或密钥。仓库现存的本机用户路径残留与处置决策见 [E4 §6.1–6.3](./E4-配置运行参数与占位符字典.md#61-已核实状态2026-09-11-实测)。
7. **不插图**：界面一律用"界面速览"文字描述代替截图（`AGENTS.md` 禁止提交截图类生成产物，且界面在持续演进、截图会迅速过期）。详见 [D2 §9](./D2-总控台使用手册.md#9-关于插图)。
