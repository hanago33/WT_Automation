本模块由两个相互独立的子域组成：
- `docs/`：以 Python 脚本为唯一入口，通过“数据块 + XML 拼装”的方式直接构造 Office OpenXML（.docx）和 PowerPoint（.pptx）文件结构，不依赖第三方文档库。
  - `generate_academic_paper_docx.py`：将论文正文按 `(kind, text)` 元组序列组织在 `build_blocks()` 中，再由 `build_document_xml()` / `build_styles_xml()` / `build_content_types_xml()` 等函数拼接出 `[Content_Types].xml`、`word/document.xml`、`word/styles.xml`、`_rels/.rels`、`docProps/core.xml`、`docProps/app.xml` 等标准部件，最终用 `zipfile.ZipFile` 打包成 .docx；遇到 `PermissionError` 时自动调用 `versioned_output_path` 追加时间戳生成版本化输出。
  - `generate_project_ppt.py` / `generate_project_ppt_com.py`：使用 python-pptx 构建 5 页版 PPT，并通过 `save_with_fallback` / `write_text_with_fallback` 实现同名文件被占用时的版本化回退；同时同步生成配套的 Markdown 讲稿。
  - `docs/__pycache__` 与若干 `.docx`/`.pptx` 成品均为上述脚本的输出产物。
- `website/`：纯静态单页网站，`index.html` 作为入口，`styles.css` 定义中车品牌配色变量，`script.js` 负责滚动动画与导航交互，`README.md` 记录本地 `python -m http.server 8000` 启动方式及 GitHub Pages/Gitee/Vercel 等部署方案。

依赖方向：两个子域彼此无代码级耦合，仅共享同一仓库中的业务事实（如 46 步流程、119.597s 耗时等），由脚本硬编码或 README 引用。
