# WT_Automation 项目结构树

> 说明：
> 1. 本结构树用于论文、汇报和项目说明场景。
> 2. 为保证展示简洁，`docs` 目录中已隐藏以下内容：
>    - 论文初稿类文件
>    - 项目讲解材料类文件
>    - `academic_paper` 相关生成脚本
> 3. OCR 二进制工具、历史日志和大量运行报告未完全展开，仅保留代表性层级。

## 二、按功能划分的结构说明

### 1. 调度与启动层

```text
WT_Automation.robot
resources/
WT_AUT_recorded.py
WT_Launcher.py
启动WT自动化总控台.bat
```

职责说明：

- 负责读取项目配置、组装运行参数并启动 WT 自动化主流程。

### 2. 流程定义与执行层

```text
flow_definition.json
flow_packages/
flow_excel_io.py
wt_flow_executor.py
wt_business_steps.py
```

职责说明：

- 负责定义业务流程、管理步骤编排，并将动作解释执行到具体窗口交互中。

### 3. 控件定位与交互层

```text
wt_flow_locator.py
wt_window_helpers.py
wt_projection_helpers.py
image_templates/
control_maps/
```

职责说明：

- 负责窗口筛选、控件评分定位、相对区域交互、模板兜底与 OCR/图像辅助。

### 4. 编辑与转换层

```text
WT_Flow_Editor.py
wt_flow_editor_utils.py
wt_action_schema.py
wt_flow_validation.py
flow_recorder_converter.py
```

职责说明：

- 负责流程可视化维护、动作字段约束、统一校验，以及录制结果向正式流程定义的转换。

### 5. 报告、测试与调试层

```text
wt_run_reporting.py
logs/
tests/
.dbg/
debug_screenshots/
artifacts/
```

职责说明：

- 负责运行结果输出、失败回溯、最小回归测试以及调试信息沉淀。
