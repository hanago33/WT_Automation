单文件实现，按职责分为四层：
- 配置持久化层：`_load_saved_config` / `_save_config_to_file` 读写同目录下的 `_gui_config.json`。
- HTTP 路由层：`AgentGUIHandler` 继承 `BaseHTTPRequestHandler`，GET `/` 返回内嵌 HTML 模板，所有 `/api/*` 请求统一交给 `handle_api` 分发（`/api/config` GET/POST、`/api/test-connection`、`/api/schemas`、`/api/skills`、`/api/chat`）。
- Agent 适配层：`_build_agent` 动态导入 `WT_AUTOMATION_Agent.DslAgent/DslAgentConfig`，`_build_context` 组合 `control_index.build_context_for_agent` 与 `skill_bridge.load_all_skills_text`，将外部能力注入到聊天/转换流程中。
- 前端 UI 层：`HTML_TEMPLATE` 是完整的单页应用（侧边栏配置 + 主聊天区），通过 `fetch` 调用后端 API，支持 chat/step/sequence 三种模式。
进程入口为 `main()`，通过 `find_free_port(8765..8799)` 自动选端口并用 `webbrowser.open` 打开浏览器；批处理脚本 `启动WT_AI助手.bat` 作为 Windows 快捷菜单，先 `start` 预打开浏览器再 `python -m WT_AUTOMATION_Agent.gui` 启动服务。
