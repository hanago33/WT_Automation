## 四、工程事件记录（教训）

本次编辑过程中，有一批改动**误落在主目录**（应在 worktree 内）。发现后的处理：
将主目录改动导出 patch → `git apply` 到 ai14 → 校验两份 patch **SHA256 逐字节一致** →
`git restore -- <4 个文件>` 还原主目录（当前干净）。

教训：编辑前先确认目标路径属于当前 worktree；批量编辑后可 `git -C <各目录> status` 复核归属。
