## 最值得先看的十项发现（TL;DR）

1. **三进程架构**：设计器 / Python 引擎 / UIA 定位 Provider 独立进程 + 命名管道 + 本地 HTTP API(:31500)。UIA 挂起只死 Provider（WT 已实测 742s 挂起只能靠探针绕）。
2. **统一元素接口**：UIA/MSAA/Java/SAP/**图像匹配**/**AI 定位** 全实现同一 Element 接口——降级链天然成立。
3. **输入三通道**：`simulate|clipboard|automatic` 一参数切换；外加驱动级(interception)与 AutoIt 后台通道。
4. **IME 防线全家桶**：force_ime_ENG + 剪贴板粘贴法 + click_before_input + focus_timeout + send_key_delay + 特殊键转义。
5. **18 参的输入指令**：`win32.element.input` 把"填个文本框"做成了 18 个参数的完备工程（影刃参数之王）。
6. **超时三态 + 等待输出 bool**：0/-1/N 全库统一；等待指令返回 `wait_result` 而非抛错。
7. **图像是一等公民**：独立图像库 + wait/click/hover/exist 指令族 + 多图组 + wait_all + 限域搜索 + 阈值参数化。
8. **执行审计五层证据链**：每指令参数值快照(SQLite+gzip) → 失败截图 → 分组件日志 → 录屏环形缓冲(30s 分段自动清理) → 卡死主线程栈转储。
9. **schema 四合一**：一份指令元数据同时生成属性面板、docstring 文档、机器可读总目录、AI 技能文档（xbot-sdk SKILL.md）。
10. **弹窗守护**：`add_monitor_record`——注册"发现指定弹窗就点掉/触发流程"的后台监控，长流程不被突发弹窗卡死。
