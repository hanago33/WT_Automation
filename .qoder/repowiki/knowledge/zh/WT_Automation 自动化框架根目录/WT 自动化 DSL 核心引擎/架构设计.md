本模块按职责拆分为四个子层，通过共享的 `wt_action_schema.py` / `wt_action_defaults.py`（动作元数据与默认值）和 `wt_control_index.py`（控件库索引）作为跨层契约进行耦合：
- flow_execution_runtime（`wt_flow_executor.py`, `wt_flow_locator.py`, `wt_flow_validation.py`, `wt_flow_editor_utils.py`, `wt_projection_helpers.py`）负责解析 `flow_definition.json`、调度步骤、定位控件并投影结果；其所有外部依赖（步骤定义获取、控件点击、日志、报告等）均通过 `configure_flow_executor()` 注入的全局回调函数实现解耦。
- business_step_catalog（`wt_business_steps.py`, `wt_action_schema.py`, `wt_action_defaults.py`）维护步骤注册表与 LLM 可读的控件库索引，同样通过 `configure_wt_business_steps()` 注入依赖，供执行器与 Agent 共同消费。
- ui_window_helpers（`wt_window_helpers.py`）封装 AutoCAD/地质建模软件的窗口发现、文件对话框与图像模板匹配等底层 UI 交互。
- reporting_and_io（`wt_run_reporting.py`, `flow_excel_io.py`, `flow_recorder_converter.py`）提供运行 JSON 报告、Excel 双向导入导出以及 pywinauto_recorder 脚本到 WT AST 的转换。
四层之间仅通过上述元数据与索引文件耦合，执行器依赖业务目录获取步骤定义，再调用 UI 辅助完成具体操作，最后由报告/IO 层持久化结果。
