# WT_Automation 项目结构与依赖清单

## 当前目录分层

- 根目录: 保留 WT 项目的核心运行文件，如 `WT_Launcher.py`、`WT_AUT_recorded.py`、`WT_Flow_Editor.py`、`flow_definition.json`
- `docs/`: 存放项目讲解材料、讲稿、结构说明等文档
- `samples/flows/`: 存放历史迁移样例流程定义与样例 Excel
- `samples/recorder_scripts/`: 存放 recorder 录制样例脚本和下拉操作示例
- `samples/legacy_tests/`: 存放历史迁移的旧测试脚本，供对照参考
- `artifacts/legacy_logs/`: 存放历史迁移的旧日志、旧 UI-TARS 输出和旧 Robot 报告
- `tools/ORC/`: 项目内 OCR 组件，模板制作器会优先从这里查找 `tesseract.exe`
- `tools/dev_utils/`: 存放模型连通性、小工具等开发辅助脚本
- `image_templates/`: 模板库与模板索引
- `resources/`: Robot / 项目运行资源配置

## 已迁入的项目内组件

- 流程主控台、执行器、流程编辑器、Excel 导入导出、recorder 转换器
- 模板制作器、模板库、模板索引
- 样例流程副本、样例录制脚本、旧测试脚本
- OCR 工具目录 `tools/ORC`
- 开发辅助脚本目录 `tools/dev_utils`

## 外部依赖但未内置复制的工具

- `UI-TARS-desktop` 仓库
  - 默认仍可配置到本机已有路径
  - 需要 Node.js 环境和对应仓库依赖
- `Inspect` 或 `Accessibility Insights`
  - 用于半自动控件信息采集与对照查看
  - 不属于项目源码内文件，因此未直接打包进 WT 项目
- Python 运行环境
  - 推荐 Python 3.11
- pip 依赖
  - `openpyxl`
  - `opencv-python`
  - `Pillow`
  - `numpy`
  - `pytesseract`
  - 以及原项目执行器所需的 `pywinauto`、`pyautogui`、`pywinauto_recorder` 等

## 本轮清理说明

- 已保留 `UI-TARS-desktop` 的原有调用方式、默认模型与 key，确保 WT 项目继续沿用原项目的 SDK 调用链路
- 已保留 `launcher_state.json` 中的默认模型、baseURL、repoRoot 和 configPath，便于直接复用原有 AI 调用入口
- 已仅清空与旧业务流程直接绑定的目标软件路径类默认值，如 WT 执行器中的程序路径、输入路径和输出路径
- 已保留历史样例资料，作为迁移参考资产，不会作为 WT 默认流程执行入口
