- 业务步骤函数统一接受一个 `_context` 参数并通过 `_GET_STEP_PARAM(context, step_id, key, default)` 读取 DSL 中传入的参数，对缺失键返回硬编码默认值。
- 对外部 UI 交互（点击、右键、菜单选择、对话框输入）一律通过模块级 `_CLICK_*` / `_RIGHT_CLICK_*` / `_TYPE_PATH_INTO_OPEN_DIALOG` 等回调进行，而非直接调用 pywinauto_recorder，从而在 `configure_wt_business_steps` 中完成依赖注入。
- 每个业务步骤内部先 `_LOG_STEP("...")` 记录意图，再执行 UI 操作，并在关键节点插入 `time.sleep(N)` 等待窗口响应。
- 动作元数据采用“常量字典 + 查询函数”模式：`ACTION_SCHEMAS` 集中声明，`get_action_schema` / `build_action_schema_hint` 负责归一化名称并生成描述文本。
- 控制项索引函数对 JSON 源加载统一走 `_load_json`，失败时静默返回 None，保证 index 构建不因单个文件损坏而中断。
