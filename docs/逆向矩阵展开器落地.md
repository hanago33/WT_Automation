## 1. 代码来源（逆向 provenance，Observed）

实现 `WT_Automation/mup_matrix_expander.py`（2197 行，`mup_matrix_expand_alt.py` 为 antigravity 独立反推互证版）。来源自控于文件头 docstring：

- **频率矩阵**：`MTDWRServices.dll` `MTDWRExportMatrix`(`ResultMatrixFrequency`, IL RVA 0x34258)。每个数据格是直接 `wrp.GetValue(key, dataSense, floor(angle), speed)` 读取：16 方向（360/NBDIRECTIONS）× 风速 1..NBWINDSPEEDS-1。
- **`.wri` 13 列 schema**：`MTDWRServices.dll` `MTDWriterWRResultIEC.Write`(IL RVA 0x30aa8)。**`.wri` 是 IEC 地形复杂度摘要,不是低频矩阵**——不含 Frequency(data sense 9)/Weibull A·K(42/43)/Mean wind speed(44)。
- **`.wrp` 二进制布局**：`MTDWRMPToolbox.dll` `MTDWRPObjectsHeaders`/`MTDWRPBlockHeaders`。

**红线遵守**：`All numbers are read as stored. No provider, licence or HPC call is made.` 纯只读、无许可调用。物理有效展开路径 = `.wrp → 16×59`；`.wri` 缺频率数据时 **fail closed,不虚构分布**（`expand_from_wri()` 抛 `WriNotFrequencyData`）。

## 5. Excel / IEC 边界（更正,IL 证据）

**此前的"必须 GUI"不准确**——原因是 Vault **根本没有 Excel 成品**，不是"拿不到"：
- `MTDWRAAnalysisExportExcelBase.Write` 调 `MTDExportExcel.CreateApplication` → `Microsoft.Office.Interop.Excel.Application` COM,逐单元格生成后由 Excel 保存,**无磁盘模板**。
- `DEMO (1)_S2.xlsx` = **17 sheet（平均+16 方向）× 46×46** 平表
- `IEC` 工作簿 = **5 sheet × 23×7**,数值来自 .wrp sense 39/38/41/53 等
- 这些均可从 .wrp data sense 精确取到（已在 DEMO xlsx 抽样核对验证）。

**结论**：数据层可用 `openpyxl` 生成数据等效 xlsx,并以现有样本逐格验收——但"和 MUP 一模一样"的合并单元格/样式/公式/图表/本地化需移植 Excel COM 行为（49+22 方法）,工作量大、版本敏感,不硬做。
