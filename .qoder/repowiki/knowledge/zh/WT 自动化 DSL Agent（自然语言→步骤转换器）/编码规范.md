- 所有对外 API 使用 dataclass 定义配置对象（DslAgentConfig/DslContext），并通过 __post_init__ 处理环境变量回退逻辑。
- Action 元数据集中在单一字典常量（ACTION_SCHEMAS/ACTION_DEFAULT_CONFIGS）中声明，通过 get_action_names/get_action_schema 统一访问，新增 action 只需修改该字典。
- LLM 交互统一通过 Function Calling 模式：先定义 tools schema，再解析 tool_calls，lookup 类工具（find_control/control_tree）结果作为 tool 消息回灌形成多轮循环。
- 模块间通过可选导入（try/except ImportError）实现松耦合，如 control_search 不可用时降级为 fallback 行为而不中断整体流程。
- 配置文件与持久化数据统一使用 JSON 格式，路径通过 os.path.exists 检查后安全加载，解析失败返回空字符串而非抛异常。
