# WT_Automation Agent 使用指南（Agent Usage Guide）

> DSL Agent 是一个基于自然语言的自动化流程生成工具，帮助用户用对话方式快速构建 WT_Automation 流程步骤。

## 一、启动方式

### 方式1：命令行启动
```bash
cd d:/My_RF_Project/WT_Automation
python -m WT_AUTOMATION_Agent.agent
```

### 方式2：双击启动
```
双击 "WT_AUTOMATION_Agent/start_agent.py"
```

### 方式3：通过 WT_Launcher
在 WT 总控台中选择「启动 DSL Agent」

启动后会自动打开浏览器：`http://localhost:8765`

---

## 二、界面说明

```
┌─────────────────────────────────────────────────────────┐
│  ⚙️ 配置侧边栏        │      💬 对话主区域              │
│  ─────────────────    │  ───────────────────────────    │
│  Base URL: [____]     │  [当前会话信息栏]               │
│  API Key:  [____]     │                                │
│  [连接]                │  [消息历史...]                  │
│  ─────────────────    │                                │
│  💬 会话列表            │  ───────────────────────────    │
│  • 会话1 (活跃)         │  [输入框...]  [发送]            │
│  • 会话2               │                                │
│  [+ 新建会话]           │                                │
└─────────────────────────────────────────────────────────┘
```

### 主要区域
| 区域 | 功能 |
|------|------|
| **配置侧边栏** | 设置 API 地址、API Key，选择模型 |
| **会话列表** | 管理历史会话（新建/加载/重命名/删除） |
| **对话主区域** | 显示消息历史和输入框 |
| **模式切换** | 切换「对话」「单步转换」「序列转换」模式 |

---

## 三、配置说明

### 必须配置
| 字段 | 说明 | 示例 |
|------|------|------|
| **Base URL** | LLM API 地址 | `https://api.deepseek.com` 或 `http://localhost:11434` |
| **API Key** | API 密钥 | `sk-xxxxxx` 或 `ollama` |
| **模型** | 模型名称（可选） | `deepseek-chat` 或 `qwen2.5` |

### 连接测试
点击「连接」按钮测试配置是否正确。连接成功后：
- 按钮变为绿色 ✓ 已连接
- 侧边栏变为深色主题
- 可以开始对话

## 四、使用模式

### 1. 对话模式（默认）
直接用自然语言描述需求：

```
用户：帮我创建一个「新建工程」流程，包括设置项目名称和保存路径
Agent：我来帮你创建这个流程...
      [生成的步骤 JSON]
```

### 2. 单步转换模式
将自然语言描述的单个操作转换为步骤：

```
用户：点击「文件」菜单，然后选择「新建工程」
Agent：[生成单步步骤 JSON]
```

### 3. 序列转换模式
将多步骤操作序列转换为步骤列表：

```
用户：1. 打开文件菜单
      2. 点击新建工程
      3. 输入项目名称
      4. 点击确定
Agent：[生成多个步骤的 JSON 数组]
```

## 五、会话管理

### 自动创建会话
- **首次发送消息时**：会自动创建会话，标题为消息前30个字符
- **后续消息**：自动追加到同一会话

### 手动管理会话
| 操作 | 方法 |
|------|------|
| **新建会话** | 点击侧边栏「+ 新建会话」 |
| **加载会话** | 点击会话列表中的任意会话 |
| **重命名会话** | 点击会话右侧 ✏️ 图标 |
| **删除会话** | 点击会话右侧 🗑️ 图标 |

### 会话持久化
- 所有会话自动保存到 `WT_AUTOMATION_Agent/history/` 目录
- 每次发送消息时自动保存
- 关闭浏览器后重新打开，会话仍然保留

## 六、常用命令

在对话中输入以下命令：

| 命令 | 功能 |
|------|------|
| `/schemas` | 查看所有可用的 Action 类型 |
| `/skills` | 查看所有已加载的 Skill 知识 |
| `/clear` | 清空当前对话消息 |
| `/help` | 显示帮助信息 |

## 七、生成结果处理

Agent 返回的结果类型：

### 1. 步骤 JSON
```json
{
  "stepParams": {"projectName": "MyProject"},
  "actionConfig": {
    "action": "click",
    "targetMethod": "name,Edit",
    "uiPath": "新建工程对话框.projectName"
  }
}
```

### 2. 步骤数组（序列模式）
```json
[
  {"stepParams": {}, "actionConfig": {"action": "menu_select", "targetValue": "文件,新建工程"}},
  {"stepParams": {}, "actionConfig": {"action": "type_text", "targetMethod": "name,Edit", "text": "MyProject"}}
]
```

### 3. 使用结果
- **复制**：点击结果区域的复制按钮
- **直接使用**：在 WT_Automation 中自动加载
- **导出**：保存为 JSON 文件

## 八、故障排除

### 连接失败
1. 检查 Base URL 是否正确（包含协议和端口）
2. 检查 API Key 是否有效
3. 确认网络可以访问 API 服务器
4. 如果使用本地 Ollama，确认服务已启动：`ollama serve`

### 消息发送失败
1. 检查配置是否已保存（刷新页面后配置应保留）
2. 检查 API 限额或余额
3. 查看浏览器控制台（F12）的错误信息

### 会话丢失
- 会话保存在 `WT_AUTOMATION_Agent/history/` 目录
- 如果目录被删除，会话会丢失
- 建议定期备份 `history` 目录

## 九、快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 换行 |
| `Ctrl + L` | 清空对话 |

---

## 十、注意事项

1. **首次使用前先配置**：不配置 API 无法对话
2. **会话自动保存**：无需手动保存
3. **长消息分段**：输入框支持 Shift+Enter 换行
4. **模型兼容性**：推荐使用支持 function calling 的模型（如 DeepSeek、GPT-4、Qwen 等）
