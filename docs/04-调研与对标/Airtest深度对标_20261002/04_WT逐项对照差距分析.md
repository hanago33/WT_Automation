## 3. 性能复杂度模型（估算，供验收基线参考）

设全屏 1920×1080（H=W 意义下记像素数 N≈2.07M），模板 ~60×40：

| 方案 | 每轮轮询成本构成 | 估算 |
|---|---|---|
| WT 现状 | 7 档 × 全屏（或 region）matchTemplate，灰度；命中后仍扫完 | 7 × N 级相关运算；按 pyscreeze+numpy 经验每档全屏约 20-60ms，一轮 **≈150-400ms**，且轮询间隔另加 0.4s |
| mstpl 移植后 | 预测区裁剪（~500×300≈0.15M）× 预测比例区间小步扫（如 20 步）× 达阈值即退 | 命中场景通常 **1-3 档即退**，每档 0.07×N 级 → 一轮 **≈5-30ms** |
| 量级差 | — | **单轮约快一个数量级**；等待 8s 场景下总轮询次数不变但每轮占用大幅下降 |

附注：① 以上为量级估算（matchTemplate 耗时随图内容/缓存状态波动），落地后以 pytest 性能 smoke 与真实流程计时校准；② WT 现状里 pyautogui.screenshot 每轮全屏截一次（PIL/GDI 拷贝），本身即 30-80ms 量级，是另一个可独立优化的常数项（阶段 D mss 评估）。

## 4. 准确率风险清单（现状代码走读发现）

1. **灰度单段判定**：形状相同、颜色不同的命中会被接受（如工具栏图标组、状态色变体）。→ 两段式置信度修复（阶段 B）。
2. **全局最优跨尺度比大小**：错误尺度的噪声峰可能高于正确尺度，选错位置且无告警。→ 达阈值早退 + 复验修复（阶段 B）。
3. **锚定像素缺失**：`TM_CCOEFF_NORMED` 归一化放大微差，低纹理纯色区域分数虚高。→ cal_confidence 锚定技巧修复（阶段 B）。
4. **模板含窗口装饰**：模板若截到边框/阴影，窗口位置变化后系统性失配（debug-relative-region-offset.md 等案例的隐性因素）。→ focus_rect 式去边约定 + region 复用（阶段 A/C）。
5. **DPI 漂移整段漏档**：0.15 步进跳过中间尺度。→ 比例预测修复（阶段 B）。

## 5. 不建议照抄的 6 项（与理由）

| # | 项 | 理由 |
|---|---|---|
| ① | `G` 全局单例 + metaclass property | WT 依赖注入模式（configure_*）可测性更强；全局状态与队列多线程模型冲突 |
| ② | 四平台 Device 抽象 | WT 只有 Windows，抽象成本无回报；只借"通道参数化"思想 |
| ③ | six/PY2 兼容层 | 纯历史包袱（requirements 锁 six<=1.16 即为兼容） |
| ④ | 特征点链优先落地 | 桌面固定软件 + 模板可控场景增益小；BFMatcher 慢；等 A-C 阶段误报率数据说话 |
| ⑤ | `record_pos` 按屏宽归一（G18 实验遗产） | 语义隐晦（delta_y 也除以 W）；WT 用已有 `region` 字段更直观精确 |
| ⑥ | cocos_min_strategy 设计分辨率缩放 | 游戏行业遗产；WT 桌面软件用 `capture_resolution` 直接比值即可 |

## 6. 与影刃对标结论的合并视图

影刃对标（docs/04-调研与对标/影刃RPA深度对标_20261002/）给出 P0×6 + P1×8 + P2×4。本次 Airtest 调研与其的映射关系：

| 影刃 P0/P1 项 | Airtest 证据 | 合并结论 |
|---|---|---|
| P0-3 重试退避+超时三态 | loop_find 超时/间隔/异常类型化（cv.py:40-82）；FIND_TIMEOUT 两档 | 实现时异常类型与超时常量语义向两者同时看齐 |
| P0-4 图像参数入库+图像等待条件 | Template 描述符两级参数（cv.py:127-136）+ templates_index.json 已有 region | **Airtest 提供了比影刀更可直接落地的实现路径**（同技术栈） |
| P0-5 防休眠+卡死登记 | intervalfunc 钩子（cv.py:74-75）；录屏 fps/降载（win.py:650-739） | 心跳挂点取 Airtest 设计、缓冲策略取影刀 |
| P1 每步输入输出快照 | @logwrap 参数值审计（logwraper.py:95-164） | `inspect.getcallargs` 方案可直接并入 run report |
| P1 统一目标抽象 | TargetPos 九宫格 + Template 描述符 | 目标描述符字段集以两者并集为蓝本 |
| P0-1 输入通道参数化 | 虚拟键/扫描码双通道（ctypesinput.py） | 影刃三通道为主，Airtest 扫描码通道并入通道清单 |

**最终判断**：图像域的 P0-4 改造以 Airtest 为唯一实现蓝本（影刀只提供了"应该做"的需求）；输入域 P0-1/P0-2 影刀为主、Airtest 补细节；审计域两者并取。
