本包采用「核心 + 桥接 + 入口」分层架构，所有子模块围绕 DslAgent 组装：
- 核心层 `agent.py` 定义 `DslAgentConfig`/`DslContext`/`DslAgent`，通过 `_build_tools_definition()` 把 `schemas.ACTION_SCHEMAS` 动态生成 Function Calling 工具定义，再调用 OpenAI-compatible `/chat/completions`；响应经 `_parse_tool_calls` → `_raw_to_full_step` → `validate_step` 转为下游可执行的步骤 JSON。
- 上下文注入层：`skill_bridge.py` 从 `skills/*.md` 与内置 Skill 扫描并合并为纯文本，`control_index.py` 从 flow_definition.json 构建控件索引，两者都写入 `DslContext` 后拼入 `build_system_prompt` 的 System Prompt，使 LLM 在生成时具备领域知识与控件库。
- 扩展能力层：`parameter_scan.py` 提供 `add_parameter_scan` 工具与 `ParameterScanner`，被 agent 的 tool 定义与系统提示共同引用，实现 Excel 驱动的参数化流程生成。
- 入口层：`cli.py` 解析 argparse 参数，按需导入 `DslAgent`、`build_context_for_agent`、`load_all_skills_text` 并组装上下文；`gui.py` 复用同一套 Agent 构造 HTTP 服务，共享所有业务逻辑。
- 契约层：`schemas.py` 是跨模块唯一的事实来源，所有 action 枚举、默认值、校验规则均由此导出，确保 CLI/GUI/Agent/Skill 描述保持一致。
- 辅助层：`history_store.py`、`memory.py`、`knowledge_base.py`、`control_search.py`、`flow_ops.py`、`log_diagnosis.py` 等模块被 agent 按需 import，提供对话历史、内存、知识库检索、控件搜索、流程操作与日志诊断等横向能力。
