- LLM 配置统一走 `DslAgentConfig`，优先构造函数参数，其次读取 `WT_DSL_BASE_URL`/`WT_DSL_API_KEY`/`WT_DSL_MODEL` 环境变量，禁止硬编码密钥。
- System Prompt 一律通过 `build_system_prompt(context)` 拼装，将 action_schema、Skill 文本、控件索引、项目描述等按固定顺序拼接，避免分散字符串拼接。
- 新增 RPA action 必须先在 `schemas.py` 注册（名称、label、description、默认 config、校验规则），再由 `_build_tools_definition` 自动暴露给 LLM，禁止绕过 schema 直接写死。
- Skill 内容以 `skills/*.md` 或 `Help_document/*` 文件形式声明，通过 `skill_bridge.load_all_skills_text()` 统一加载，不在 Python 代码中内嵌长文本。
- CLI 与 GUI 入口只负责参数解析与依赖导入，不重复实现 Agent 调用逻辑，业务路径集中在 `agent.py`。
