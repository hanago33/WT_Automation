根目录作为顶层装配点，将子模块按职责分层组织：`core_engine` 提供 `wt_flow_executor.py` / `wt_flow_locator.py` / `wt_business_steps.py` 等核心运行时；`top_level_scripts` 暴露 `WT_Launcher.py`、`WT_Flow_Editor.py`、`WT_AUT_recorded.py` 三个对外入口，分别承担 GUI 启动、流程编辑与录制回放；`flow_packages/` 与 `control_maps/`、`image_templates/` 作为数据资产被上层通过 JSON 注册表加载；`automation_agent` 以 DslAgent 为自然语言→RPA 步骤的桥接层，依赖 core_engine 的 action 契约；`tools_and_utilities` 下的采集/转换脚本（如 `build_control_map_library.py`、`flow_recorder_converter.py`）产出上述资产供编辑器与执行器消费；`tests/` 覆盖核心转换与执行逻辑，`docs_and_papers/` 生成论文与展示网站。根级 `PROJECT_ARCHITECTURE.md` 与 `README.md` 统一描述推荐工作流（采集控件 → 编辑器新建/导入 → schema 校验 → 运行查看报告），并通过 `.gitignore` 排除 `launcher_state.json`、`.env*`、`logs/`、截图等本地状态。
