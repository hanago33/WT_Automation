- Action 能力以「schema 字典 + 默认配置字典」双表驱动，新增 action 只需在 `ACTION_SCHEMAS` 与 `ACTION_DEFAULT_CONFIGS` 各加一条，无需改动逻辑代码。
- LLM 客户端统一通过 `_call_llm` 封装，使用 `(connect_timeout, read_timeout)` 二元超时与 `status_forcelist` 配合指数退避重试，所有 HTTP 出口共享同一模式。
- System Prompt 采用 `parts.append(...)` 分段拼接再 `"\n".join(parts)` 的方式，按「动作说明 → 领域知识(Skill) → 控件库 → 已有步骤 → 项目描述 → 输出规范 → 参数扫描规则 → 示例」固定顺序追加。
- 对外暴露的公共函数对空/None 输入做规范化处理（如 `str(action_name or "click").strip() or "click"`），保证 schema 查询永不抛异常。
- Skill 加载器按扩展名分派到独立 `_load_xxx_skill` 函数，失败路径返回 None 或带占位内容的 `SkillInfo`，使 `discover_skills` 可安全遍历任意目录。
