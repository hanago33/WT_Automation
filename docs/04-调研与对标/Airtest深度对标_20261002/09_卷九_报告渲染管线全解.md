## 2. 调用树重建 `_analyse`（:100-127）

```python
for log in self.log:
    depth = log['depth']
    if depth == 0:   steps.append(log)                    # 无栈日志（G.log 直记）
    elif depth == 1: step["__children__"] = children_steps; steps.append(step)   # 顶层 API 步骤
    else:            children_steps.insert(0, log)        # 内层函数（loop_find/_cv_match 等）归入 children
translated_steps = [self._translate_step(s) for s in steps]
if translated_steps and translated_steps[-1].get("traceback"):
    self.test_result = False                              # 最后一步带 traceback = 整体失败
```

要点：**树的重建只依赖 depth 字段**（`running_stack` 深度，logwraper.py:61），无需显式父子 ID；children 倒序插入、渲染时再反转。最后一步的 traceback 决定整体结果——"报告失败判定"只有这一条规则。

## 3. 匹配结果可视化闭环 `_translate_screen`（:156-215）——本卷最核心

```python
for item in step["__children__"]:
    if item["data"]["name"] == "try_log_screen":          # ① 找到本步骤的截图
        snapshot = item["data"]["ret"]                    #    try_log_screen 的返回值
        screen['src'] = ...; screen['thumbnail'] = ...(max 300px 缩略图, :228-240)
for item in step["__children__"]:
    if item["data"]["name"] == "_cv_match" and isinstance(item["data"].get("ret"), dict):
        cv_result = item["data"]["ret"]                   # ② 找到匹配结构化结果
        screen['pos'].append(round(...cv_result['result']))
        screen['rect'].append(self.div_rect(cv_result['rectangle']))   # ③ 四角→{left,top,w,h}
        screen['confidence'] = cv_result['confidence']    # ④ 置信度直接上报告
# touch/assert_exists/wait/exists 步骤：用最终 ret 修正显示 pos（:199-204）
# swipe：起点+向量渲染箭头（:206-211）
```

**这就是卷二"结构化匹配结果"的最终价值闭环**：`_cv_match` 返回的 `{result, rectangle, confidence}` 经 JSONL 原样落到日志，渲染时被检索出来，在 HTML 里以"截图 + 高亮矩形 + 点击点 + 置信度数字"的形式呈现。**排障时你看到的就是机器人当时看到的**——哪张图、框在哪、分多高。`div_rect`（:298-307）把四角点序转成 CSS 可用的 left/top/width/height。

前端模板（log_template.html + JS）按 `screen.src/thumbnail/rect/pos/vector/confidence` 渲染叠加层；多结果（find_all）时 rect 为数组。
