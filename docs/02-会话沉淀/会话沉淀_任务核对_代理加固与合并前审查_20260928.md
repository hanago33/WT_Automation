## 二、代理假红根因（新发现）

在 main 跑全量出现 `54 failed / 1062 passed`，失败全部集中在 HTTP 服务类测试。

**根因**：会话 shell 注入 `HTTP_PROXY=http://127.0.0.1:7890`（本机代理软件），
`urllib` 对 `127.0.0.1` 的回环请求也走代理 → 全部"健康检查无响应"超时。

**验证**：`NO_PROXY=127.0.0.1,localhost` 下 102 项服务类测试全过，产品代码零回归。
