- HTTP 响应统一通过 `_json_response(handler, data, status)` 封装，设置 `Content-Type: application/json; charset=utf-8` 与 `Access-Control-Allow-Origin: *`，并捕获连接断开异常静默忽略。
- 模块级延迟导入（`from ... import ...` 放在函数体内）用于避免 GUI 启动时加载重型依赖（如 `DslAgent`、`schemas`、`skill_bridge`）。
- 配置字段在保存/读取两端保持键名一致（`base_url`、`api_key`、`model`、`timeout`、`max_retries`、`retry_backoff`、`retry_codes`），并在 GET 端对 `retry_codes` 做 list/tuple → 逗号分隔字符串的兼容转换。
- API 路由采用 `route == "/api/xxx" and handler.command == "GET/POST"` 的 if-chain 分发，未命中路径统一返回 `{"error": "Not Found"}` 404。
