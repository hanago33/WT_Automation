## 6. 可搬动性规则

| 类别 | 能否移动 | 说明 |
|---|---|---|
| 根级 `wt_*.py` / `flow_*.py` / `mup_*.py` 核心库 | ❌ **不能搬** | 互相 `import`，搬动即断链；依赖注入设计也假设它们在同一包层级 |
| `WT_Launcher.py` / `WT_Flow_Editor.py` / `WT_AUT_recorded.py` | ❌ 不能搬 | 入口，`.bat` 与文档均按根路径引用 |
| 诊断 / 独立小工具（`diagnose_*.py` 等） | ✅ 可独立运行 | 未被 `.bat` 引用 |
| `tools/` 下的独立脚本 | ✅ 可独立运行 | 注意 `tools/ORC/` 是离线必需运行时，不能删 |
| 资产目录（`control_maps/`、`image_templates/`、`flow_packages/`） | ⚠️ 路径被多处引用 | 移动后需同步更新代码、测试、`docs/` 引用 |
| `.tmp_*` / `tmp_*` 残留 | 🧹 **应清理** | 根目录现有 11 个（`.tmp_flow_inspect*.py`、`.tmp_step1to5.py`、`tmp_analyze.py` …）。按 `AGENTS.md`，临时文件应放系统临时目录并及时清理 |
