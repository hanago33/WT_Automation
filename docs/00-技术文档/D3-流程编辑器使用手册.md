## 2. 界面组成

| 区域 | 作用 |
|---|---|
| 流程包 / 步骤树 | 按 `flowPackages[].stepIds` 组织；`collect_flow_package_step_ids`（L865） |
| **步骤详情表单** | **由 action schema 驱动**——选了动作后，字段显隐与必填提示自动变化 |
| 控件清单（`controls[]`） | 本步骤认识的控件；`actionConfig.controlId` 只能从这里选 |

> 📷 **本手册不插图**，原因见文末 §9。下面用"界面速览"代替。

### 界面速览

典型的三栏/上下布局：

| 位置 | 区块 | 怎么认出它 | 你能做什么 |
|---|---|---|---|
| **左 / 上** | 流程包与步骤树 | 按 `flowPackages[].stepIds` 组织的树；每个节点显示 `stepId` + `name` | 选中步骤、调整顺序、新建（默认链路） |
| **中 / 右** | **步骤详情表单** | 一组标签 + 输入：动作类型、目标控件、输入/参数、超时、重试、`onError`… | **选了动作后字段会自动变化**（schema 驱动） |
| **下 / 标签页** | 控件清单（`controls[]`） | 控件条目表格：`id` / `name` / `targetMethod` / `targetValue` | 从控件库导入、编辑单条、删除 |
| **底部** | 动作指引 / 必填提示 | 一行提示文字，说明"当前必填：…" | 告诉你还缺什么 |
| **工具栏** | 打开 / 保存 / 校验 / 导入 / 导出 | 扁平按钮（由 `wt_theme` 生成） | 保存即校验 + 同步注册表 |

**字段变化的关键**：在"动作类型"下拉里选了某个动作后，表单会按 `ACTION_SCHEMAS` 自动调整——
需要目标控件的动作显示"目标控件"；需要输入的显示对应输入项（标签由 `input_label` 决定）；`log` / `sleep` 这类**不显示超时字段**。

> 💡 找不到某个字段时：先确认**动作类型选对了**——多数字段"消失"其实是当前动作不需要它。

## 3. 编辑步骤

### 3.1 步骤基本字段

| 字段 | 说明 |
|---|---|
| `id` | 步骤唯一 ID（重复即报错） |
| `name` | 步骤名 |
| `enabled` | 停用后执行时跳过（记 `skipped`） |
| `windowTitle` | 目标窗口标题；**不能是"请补充"或 `<...>` 占位值** |
| `actionType` | `action` / `script` / `flow_ref` / `placeholder` |
| `topLevel` | 是否顶层步骤 |
| `packageRef` | `flow_ref` 时引用的流程包 |
| `optional` | `script` 未绑定函数时是否为"可跳过"（否则**记 failed**） |

### 3.2 选择动作

19 种动作（E1 §2）。选中后表单按 schema 变化：

| schema 元字段 | 效果 |
|---|---|
| `target_required` | 是否显示/强制"目标控件" |
| `input_required` / `input_key` / `input_label` | 是否显示输入项、绑定哪个键、表单标签 |
| `show_timeout` | 是否显示超时字段（`log` / `sleep` 为 false） |
| `suggested_columns` | 填写提示（也是 Excel 列建议） |

### 3.3 三类容易填错的字段

| 字段 | 易错点 |
|---|---|
| `postInputKeys` | 输入类动作**必须配**（`{TAB}` / `{ENTER}`），否则"输入未提交"假成功（B5 §1.1 模式 B） |
| `precondition` | 勾选类动作配 `{"condition":"toggle","expected":"off"}` 实现**幂等** |
| `continueWhen` | 关键动作配状态校验，否则无法判断"点了有没有生效"；AI 介入结果也不会被采信 |

## 4. 编辑控件

| 对话框 | 行号 | 用途 |
|---|---|---|
| `ControlPickerDialog` | L1231 | 从控件库挑选控件导入 |
| `ControlEditorDialog` | L1394 | 编辑单条控件定义（`targetMethod` / `targetValue` / `labelText` / `auxChecks` …） |
| `_load_control_library_controls(refresh=False)` | L1359 | 读取控件库候选 |

### 4.1 定位方法填写规则

- `targetMethod` 与 `targetValue` **逗号成对且段数必须一致**（否则校验报错）；
- 段内逗号用 `\,` 转义；
- 优先级建议（B3 §3）：`automation_id,control_type` → `automation_id` → `name,control_type` → `name` → `label_text` 组合 → `ui_path`；
- **同名控件务必加消歧字段**：`label_text` 或 `ui_path`（否则共享 automationId 的兄弟控件会误命中，B3 模式 N）。

### 4.2 反向写回控件库

编辑器可把控件定义回写进控件库（供后续复用）：

`_build_control_library_category`(L986) → `_build_control_library_control_entry`(L1017) → `_build_control_library_payload`(L1045) → `_merge_controls_into_library_payload`(L1067)

### 4.3 亲戚区域辅助

`RelativeRegionHelperDialog`（`WT_Launcher.py` L407）用于**量取亲戚区域坐标**——在真实界面上框选，直接得到归一化的 `x/y/width/height`，避免手填试错。

## 5. 校验与保存

| 步骤 | 说明 |
|---|---|
| 1 | 保存前自动执行 `validate_flow_definition`（步骤级 + 流程级） |
| 2 | 校验不通过会列出具体问题，**保存被阻止** |
| 3 | 保存时自动 `sync_flow_package_registry(...)`（L894）同步注册表 |
| 4 | 同步总控台当前流程路径 `sync_launcher_flow_definition_path(...)`（L924） |

**常见校验错误**（完整清单见 B2 §5.1 / E2 §6）：

| 报错 | 含义 |
|---|---|
| "目标控件 `xxx` 不存在于当前步骤细分控件清单中" | `controlId` 不在 `controls[]` |
| "targetMethod 与 targetValue 数量不一致" | 逗号段数不匹配（注意 `\,` 转义） |
| "`x` 需在 0 到 1 之间" | 亲戚区域坐标必须归一化 |
| "缺少父窗口标题" | 亲戚区域动作需 `title`，或同时给 `className`+`frameworkId` |
| "续跑条件 `xxx` 非法" | `continueWhen.condition` 不在白名单 |
| "仍是占位值" | `windowTitle` / `targetValue` 还是"请补充"或 `<...>` |
| "步骤ID `xxx` 重复出现" | stepId 重复 |

## 7. 已知问题与注意事项

| 项 | 说明 |
|---|---|
| **上帝类** | `FlowEditorApp` 约 4 450 行，GUI 与业务混杂（C2 §3.3）。改动需谨慎 |
| **白名单重建** | `normalize_step`（L978）用白名单重建步骤；**新增字段必须在此显式放行**，否则保存即丢失（E2 §7） |
| **`_launch_python_script` 重复** | 文件内 4–5 处几乎相同的 `subprocess.Popen`，抽函数时一并收口 |
| **Tk 线程安全** | 后台线程只能经 `root.after` / `_ui_safe_call` 碰 UI（B1 §8） |
| **备份习惯** | 改动前先 `.bak_<场景>_<日期>`（C4 §6） |
