- 所有 JSON 配置文件（flow_definition.json、flow_package_registry.json、launcher_state.json、editor_state.json）统一通过 `load_json_file`/`save_json_file` 读写，写入时附带 `lastUpdated` 时间戳。
- 流程定义采用三段式结构 `{runtimeConfig, flowPackages, steps}`，并通过 `_normalize_flow_payload` 或 `_normalize_payload` 做类型归一与字段过滤后再参与合并。
- 跨模块配置通过 `@lru_cache(maxsize=1)` 缓存项目设置、流程负载、运行时配置，并提供 `_refresh_flow_caches()` 统一清理缓存以便热重载。
- 对外部可选依赖（如 pyautogui）采用全局变量 + 首次导入失败缓存的模式（`_PYAUTOGUI_MODULE`/`_PYAUTOGUI_IMPORT_ERROR`），避免重复 import 开销。
- 子模块（wt_flow_executor/wt_flow_locator/wt_business_steps 等）通过模块级 `configure_*` 函数注入回调与上下文，而非构造函数传参，保持被调用侧零侵入。
