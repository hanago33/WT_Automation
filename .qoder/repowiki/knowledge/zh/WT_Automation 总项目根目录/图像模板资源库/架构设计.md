本模块为纯数据仓库，不包含任何可执行代码，由上层通过读取 JSON 索引定位 PNG 模板文件。
- 顶层 `templates_index.json` 维护全局元信息（`meta.templateCount`、`meta.categoryCount`、`lastUpdated`）以及跨子目录的模板清单；每个模板条目包含 `category`、`file_name`、`image_path`（绝对路径）、`relative_image_path`、`source_screenshot`（原始全屏截图来源）和 `region`（x/y/w/h 裁剪矩形）。
- 子目录 `Icons/`、`WT_software_Images/`、`draw_down/` 各自维护一份局部 `templates_index.json`，仅登记该目录下的模板，形成“总索引 + 分目录索引”的双层结构，便于增量更新。
- 目录按业务域划分：`Icons/` 存放按钮/图标级小图，`projection/` 子目录存放投影对话框相关控件截图，`WT_software_Images/` 存放 WT 软件界面截图，`draw_down/` 存放下载弹窗元素，`auto_cap_*` 为自动截取的临时素材。
- 依赖方向单向：上层测试脚本 → 读取 `templates_index.json` → 解析 `image_path`/`region` → 使用 OpenCV/PyAutoGUI 等完成模板匹配与点击，本模块不反向依赖任何 Python 包。
