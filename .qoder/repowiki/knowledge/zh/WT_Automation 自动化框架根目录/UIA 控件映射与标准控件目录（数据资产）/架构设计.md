本模块为纯数据目录，由上层链路编辑器在运行期扫描 WPF/Win32 进程后写入三类 JSON 产物：
- 单次会话快照：`YYYYMMDD_HHMMSS_*_window_control_map.json` / `_control_map.json`，记录一次 UIA 扫描得到的完整控件树。
- 控件库条目：`library_<窗口名>_<framework>_controls.json`，由编辑器将常用控件按 `categoryWindowTitle` + `categoryFrameworkId` 归档到独立文件，供后续用例复用。
- 聚合报告：`standard_control_catalog.json`（按 frameworkId 分组、统计 occurrences/authority）、`standard_catalog_mismatch_report.json`（定位策略不一致告警）、`总控件信息.json`（schemaVersion=1.0-master，mode=master-merged，对全部源文件做去重合并并输出 flatControls 列表）。
依赖方向单向：运行时扫描 → 写入快照/库 → 离线聚合脚本读取所有 JSON 生成 catalog 与总控清单；本目录不含任何可执行代码。
