# 会话沉淀：全套工具窗口商业化 UI 排布优化与格调升级 (2026-09-09)

## 1. 概述与设计背景

为了使 WT_Automation 自动化测试/生产套件从“工控脚本级”外观提升至“专业商业化工业软件”质感，本会话针对全套图形界面工具进行了全方位的 UI 排布优化、格调升级与设计令牌（Design Tokens）贯通。

### 核心约束与红线
1. **零业务改动**：绝对不改动任何原有的自动化执行逻辑、配置持久化结构（JSON/XML）、进程管理与网络通信协议。
2. **测试全绿**：全套自动化测试（762 项）100% 保持全绿通过，任何视觉改造都经受住回归测试验证。
3. **工作区隔离**：严格遵循 `AGENTS.md` 规范，所有开发与提交均在 `D:\My_RF_Project\WT_automation_ai`（分支 `ai/session-1`）中完成，主目录保持纯净。

## 2. 设计规范与统一视觉系统 (Design Tokens)

全面接入并贯通 `wt_theme.py` 设计体系，确立了商业化软件的标准设计语言：

| 视觉元素 | 规范标准 / 颜色代号 | 设计意图 |
|---|---|---|
| **主题主色 (Primary)** | `#2563eb` (Royal Blue) / 深灰蓝 `#1e293b` | 稳重、专业，符合工业级控制台质感 |
| **操作辅色 (Success/Warn)**| `#059669` (翡翠绿), `#d97706` (琥珀橙) | 关键动作（启动、保存、急停）醒目传神 |
| **卡片背景 (Card BG)** | `#ffffff`，搭配 `#f8fafc` 底衬 | 建立清晰的内容层级，减少视觉疲劳 |
| **边框与分割 (Border)** | `#cbd5e1` / `#e2e8f0` 细微线条 | 告别原生 Windows 98 式粗边框与生硬凹凸槽 |
| **交互动效 (Hover)** | 动态 `<Enter>` / `<Leave>` 悬停色阶变化 | 提供即时灵敏的操作反馈，消除“死板”感 |
| **微边距 (Padding)** | 按钮 `pady=4, ipady=3`；输入框 `ipady=2` | 增加触控与视觉呼吸感，文字不贴边 |

## 3. 全模块改造清单与成果明细

### 3.1 WT_Launcher.py (总控台)
- **Simple 极简模式**：
  - **双层分离工具栏**：第一层突出“全自动化执行”主操作区（大号一键启动、运行状态 Badge、醒目急停）；第二层集中紧凑型辅助功能（高级模式切换、日志查看、关于），信息密度层次分明。
  - **8 板块时序卡片扩大与排布优化**：卡槽增加外边距（`pady=4, padx=8`），卡片内部将状态图标与执行阶段名称对齐，下方进度条水平撑满，清晰呈现工序流转节奏。
  - **按钮规格放大**：主按钮加宽加大，增加微圆角与扁平色块质感。
- **Advanced 高级模式**：
  - **3-Tab 抽屉式侧边栏/分类组织**：将原本堆叠杂乱的界面整合成【执行与队列】、【参数与配置】、【辅助工具箱】三大面板。
  - **现代网格工具箱**：所有外围工具（流程编辑器、控件库采集器、模板制作器、实时探测器等）以网格卡片排列，按钮统一规格，悬停动效灵敏。
- **内置弹窗优化**：
  - **工程参数编辑弹窗 (`open_params_editor`)**：增加表单项垂直间距与内衬边距，底栏“确定保存”与“取消”按钮加宽加高并右对齐。
  - **相对区域编辑弹窗 (`open_interest_areas_editor`)**：数据表头加深背景，行高增加，按钮排列更符合现代操作流。

### 3.2 WT_Flow_Editor.py (流程链路编辑器)
- **顶部操作栏逻辑分组**：分为【工程与文件】、【节点与连线】、【视图与执行】，各功能组之间以微妙竖线隔开。
- **右侧节点检视器 (Node Inspector)**：各参数项封装为卡片视图，增加分组标题与淡色底边分割线。
- **底层组件规范化**：优化 `_grid_label_entry` 与 `_make_button_row`，使得所有属性修改弹窗的输入框和按钮均自带高质感微内边距。

### 3.3 build_control_map_library.py (控件库采集器)
- 彻底替换原生系统默认灰色 Tk 样式，注入 `wt_theme.get_palette()` 现代蓝灰主题。
- 顶部采集工具栏（启动采集、暂停、重新载入、保存）改用饱满色块与悬停动画。
- 左侧控件树与右侧属性列表增加边距与字体优化，提升长时间标定作业的舒适度。

### 3.4 control_live_detector.py (实时控件检测器)
- 保持与控件库采集器相同的现代化视觉风格，边框与底色统一。
- 实时侦测状态条与结果标签重构，信息显示更加突出醒目。

### 3.5 build_image_template_library.py (图像模板制作器)
- 接入设计令牌，左右分栏（模板树状视图 vs 图像预览画布）采用纯白卡片加细边框。
- 下方“添加模板”、“测试匹配”、“保存配置”等按键增强视觉权重与触控反馈。

### 3.6 wt_flow_graph.py (流程链路拓扑图)
- 将原生陈旧且突兀的 `tk.OptionMenu` 升级为现代扁平 `ttk.Combobox`。
- 流程拓扑节点绘制升级：从纯矩形线框优化为带微妙浅阴影与高亮边框的圆角卡片，节点类型与状态一目了然。

### 3.7 用户反馈专项提升与交互细节打磨 (第四轮升级)
- **Simple 板块边界高亮与识别强化**：
  - 边框颜色由淡浅灰提亮为深灰蓝细边框（`#cbd5e1`），消除纯白卡片在浅底上的融边与视觉疲劳；
  - 每个卡片顶部嵌入 3px 高度的品牌标识色条（Top Accent Bar），未配置为中性灰、已配置呈现科技蓝，视觉边界极其立体；
  - 标题行下方增加 1px 微妙分割浅线，并接入卡片鼠标悬停聚焦动效（Hover Highlight 至科技蓝）。
- **流程链路编辑器左右分割条拖拽卡顿根治**：
  - 将主分割窗格调整为平滑预览模式（`opaqueresize=False`），拖拽分割条时以 0ms 延迟显示响应线，鼠标释放时才一次性完成重排，彻底消除微小位移引发的递归重排风暴；
  - 在 `_build_scrollable_panel` 中加入尺寸变动阈值防抖与 `after_idle` 合帧更新，有效平抑多标签页下的尺寸抖动。
- **图像模板制作器工作区截图动态自适应撑满**：
  - 破除原先硬编码的 `CANVAS_MAX_WIDTH = 1100, CANVAS_MAX_HEIGHT = 760` 尺寸上限与 `min(..., 1.0)` 封顶限制；
  - 动态读取左侧工作区画布的实时实际宽高，截图自适应等比例撑满整个工作区窗口；
  - 绑定画布 `<Configure>` 事件，在用户最大化或缩放窗口时自动防抖重绘贴合，杜绝大黑边。
- **高级模式工具箱常用工具高亮与辨识增强**：
  - Tab 2 顶部新增【★ 核心常用推荐】高亮快捷卡片，集中呈现 6 大高频工具（打开流程编辑、进入模板制作、进入控件采集、实时控件检测、任务监控、打开日志）；
  - 下方分类列表中，高频核心工具统一加上 `★` 标识，并赋予品牌浅蓝高亮微底色（`primary_soft`）与加粗字体，主辅层级分明。

### 3.8 Simple 模式远程按钮与流程图全景展示重构升级 (第五轮专项优化)
- **Simple 模式「远程模式」按钮重构为状态胶囊按钮**：
  - 彻底废除原生简陋的 `tk.Checkbutton` 小复选框；
  - 改用现代扁平大号状态按钮：未激活显示 `💻 本地模式 (点击切远程)`（中性灰白底配深灰蓝边框）；激活显示 `☁ 远程模式 (已启用)`（醒目科技蓝 `#2563eb` 实底白字加粗）；
  - 按钮支持 `padx=14, pady=4` 舒适触控区与动态 Hover/点击反馈，同时联动主运行按钮文案及状态持久化（`_simple_save_state`），视觉协调且专业。
- **流程图（Flow Graph）全景展示页面重构与内容遮挡根治**：
  - 基础尺寸扩增至 `760x840`，自适应 `minsize(580, 500)`；
  - 顶部增加步骤总数 Badge（如 `共 18 步`），底部图例采用平滑圆点微标记；
  - 画布卡片宽度动态计算 `node_w = min(740, max(460, width - 64))`，大屏下饱满撑开；
  - 彻底根治纵向文字与图标重叠遮挡缺陷：
    * 将卡片高度统一提升至 `node_h = 108px`；
    * 第一行（`y + 13`）采用**动作胶囊与步骤名称同排并置**设计，杜绝步骤名换行下坠覆盖胶囊的问题；
    * 第二行（`y + 45`）独占整行显示目标控件（`🎯 控件：...`），宽度撑满卡片可用区域，放宽截断阈值；
    * 第三行（`y + 75`）独占整行显示等待条件或备注（`⏱ 等待：...` / `📝 备注：...`）；
  - 步骤详情弹窗由 `560x620` 扩大为 `600x660`，标题栏加装 `wraplength=540` 自动换行，长字段放宽至 1000 字符展示，彻底消除字段溢出与截断。
