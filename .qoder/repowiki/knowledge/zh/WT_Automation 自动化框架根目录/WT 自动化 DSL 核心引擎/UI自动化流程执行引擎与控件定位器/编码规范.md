- 所有对外部子系统（步骤定义查询、日志、控件点击/输入/等待等）的依赖均以模块级 `_XXX` 全局变量 + `configure_xxx(...)` 注入函数暴露，默认值为空 lambda，使模块可在无宿主环境时安全导入。
- 时间/重试间隔参数统一经 `sleep_seconds(value, default)` 归一化为非负浮点数，避免传入非法值导致异常。
- 字符串字段在解析前先做 `str(...).strip().lower()` 三件套，并对占位文本使用 `is_placeholder_text` / `_contains_placeholder_text` 判断后丢弃。
- 异常处理采用"重试 → fallbackTemplate → AI 干预 → continue/ask"固定顺序，并通过 `step_extra` 字典记录 attemptCount/retryCountConfigured/fallbackTemplateUsed/onErrorHandled 等元数据供报告输出。
- 定位器方法/值采用逗号分隔的多值语法，统一通过 `_split_locator_parts` / `build_locator_text` 成对解析，并在 validation 中校验两者数量一致。
