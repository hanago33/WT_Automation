## 三、重要：`control_live_detector.py` 不在版本控制（本地资源流转）

- **事实**：`.gitignore:96` 排除该文件（"Live detector scripts"）；它同时是
  `WT_Launcher.open_live_detector` 的功能依赖，且被 `tests/test_control_live_detector.py`
  直接 import（跑套件必需）。
- **本轮影响**：其中的 6 处修复（P0-1a/1b、P1-6、加载提示）**无法随 git 提交**。
  按项目既有流转方式（AGENTS 检查单即"从主目录拷贝该文件"）执行了**文件同步**：
  - 主目录旧版先备份至 `%TEMP%\control_live_detector_backup_20260929.py`；
  - 修复版同步至主目录，SHA256 一致性校验通过（`9E1EEB7C…`）；
  - 主目录全量 1193 passed（既有测试集全绿，零误伤）。
- **建议（待维护者决策）**：将 `control_live_detector.py` **纳入版本控制**
  （移除 .gitignore 第 96 行、`git add`）。理由：它已是产品功能依赖与测试依赖，
  不纳入会导致——① 修复难以随分支流转（本次只能手工同步）；② 新机器/新 worktree
  缺失该文件时功能与相关测试不可用；③ 无法用 git 追溯其历史修改。
