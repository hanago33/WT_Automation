- 模块级全局回调采用「空操作 lambda 默认值 + configure_* 函数覆盖」模式，使脚本在无宿主环境时仍可安全导入而不抛异常。
- 对外部不可靠 UI 操作统一采用 deadline 轮询 + 固定 sleep 间隔 + last_error 累积的模式，失败时抛出带上下文的 RuntimeError。
- 对 Inspect.exe 输出字段使用 key_map 将多种本地化键名（如 ControlType / Control Type）映射到统一的 camelCase 内部键，再经 normalize_inspect_scalar 清洗空值与包裹引号。
- 图像模板路径通过 _GET_IMAGE_TEMPLATE_DIR() + 文件名拼接获取，并在每次使用前显式检查 os.path.exists，缺失则抛出 FileNotFoundError。
