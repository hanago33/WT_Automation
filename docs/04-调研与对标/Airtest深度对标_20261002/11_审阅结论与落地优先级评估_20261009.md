## 2. 逐条审阅

### 2.1 卷四：21 维能力矩阵 + 准确率风险 —— 全部接受

**图像识别域（1~10 维）**：7 项 ❌ 缺口逐项回码核实**属实**——
- 多尺度七档硬编码（步进 0.15，远粗于 Airtest 的 0.005）；
- 索引里的 `region` 字段**从未参与匹配**（0 次读取）；
- 灰度 `max_val` 单段直判、7 档全扫无早退、全局最优可跨尺度选错；
- `confidence=0.8` 写死 4 处（`:254/:261/:421/:432`）；
- 裸 `Point` 结果（无置信度/尺度/耗时）；无特征点 / 多实例匹配。

**等待审计域（11~16 维）**：`sleep(0.4)` 写死（`:301`）、无失败钩子、无参数值审计——属实。

**设备输入域（17~21 维）**：无 mss、无扫描码发送通道、`wt_dpi.py` 存在（属实）、防休眠无——属实。

**§4 准确率风险 5 条**：灰度单段误报、全局最优跨尺度、锚定像素缺失、模板含装饰边、DPI 漂移漏档——源码级可复现，**即阶段 B 的修复目标**。

> "WT 明确领先维度"一节无改造含义，未逐项复核。

### 2.2 卷五：阶段 A~D

**阶段 A · 参数入库（0.5 天）——采纳**
`templates_index.json` 增可选字段（`threshold/rgb/scale_step/scale_max/capture_resolution`）；`image_template_index.py` 加第二索引 + `get_template_params`；采集器写 `capture_resolution`。
- 核实：`get_template_params` 不存在；采集器写入点为 `build_image_template_library.rebuild_template_index`（现写 `region`/`updatedAt`）。
- **注意**：与影刃 P0-4' 的 `match{}` 字段体系需**合并为一份 schema**（见 §4.3），避免两套并行字段。

**阶段 B · 匹配内核（1.5 天）——采纳**
新模块 `wt_image_matching.py`（比例预测 + 区域裁剪 + 早退 + 两段式复验）；`_match_template_multiscale` 改薄壳。
- 参考代码见卷六附录 A/B；**与 OpenAdapt T1（消歧门）同批**。
- 校正：调用点实为 5 处（§3-1），"零回归"更易达成。

**阶段 C · 等待与审计（1 天）——采纳**
`wait_template` + `TemplateNotFoundError` + 失败自动留证 + 心跳钩子。
- 与影刃三项对齐：P1-6 参数快照（同源思想）、P0-3' 重试装饰器（卷七 §4 的 63 行实现）、防休眠心跳经 `intervalfunc` 接入。

**阶段 D · 可选增强——触发条件制**
D1 mss（先做真实流程计时确认截图开销占比）；D2 BRISK（等 A/B/C 误报数据）；D3 扫描码（并入影刃 P0-1 通道清单）；D4 find_all（需求驱动）。

**量化验收（采纳）**：E1 同构异色拒杀固化为 pytest 用例；命中场景 ≤100ms/轮（现状 240ms）。

## 4. 落地建议

### 4.1 图像域批次 = 三份对标的收敛点

```
影刃 P0-4（需求：图像一等公民 + 等待语义 + 多图组）
  + Airtest 阶段 A/B/C（实现蓝本：参数入库 → 内核 → 等待审计，卷六带代码）
  + OpenAdapt T1（算法增补：多实例消歧门 ~60 行）
  = 完整"图像域批次"（约 3.5 人日，2~3 个 commit）
```

**该批次优先于影刃 08 卷原先的 P0-4' 建议**（原建议只含"索引统一 + 参数透传"，应升级为本批次）。

### 4.2 排期合并（与影刃 08 卷 / OpenAdapt 06 卷）

| 批次 | 内容 |
|---|---|
| 第一批（不变） | P0-6' Agent schema 同源；P0-5' 防休眠+卡死登记；P1-6 参数快照 |
| 第二批（扩充） | ① 输入通道 + 剪贴板（影刃 P0-1/P0-2' + 本卷扫描码 D3 + 卷八协商思想）；② 重试退避（影刃 P0-3' + **本卷重试装饰器**）；③ **图像域批次（本卷 A/B/C + T1）**；④ 报告可用性增强（本卷卷九四项） |
| 第三批 / 触发条件 | 阶段 D、录屏、错误码、T2/T5 治理项 |

### 4.3 落地前置：图像 schema 合并（一次定稿）

| 来源 | 字段 |
|---|---|
| 本卷阶段 A | `threshold` / `rgb` / `scale_step` / `scale_max` / `capture_resolution` |
| 影刃 P0-4' | `match{confidence, scales, grayscale, region_hint}` |
| 既有索引字段 | `region`（复用为 ROI）、`source_screenshot`、`updatedAt` |

建议形态：以阶段 A 字段为主体（有代码蓝本），`region_hint` 直接用既有 `region`，`grayscale` 与 `rgb` 二选一（建议 `rgb`，与 Airtest 一致、默认 False）。
